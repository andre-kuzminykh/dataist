Anthropic has added Mods to Claude Code, a way to change how the coding tool behaves from inside the product. The extensions can run in the command-line and desktop apps, with partial support in the VS Code extension. Anthropic has also published example Mods on GitHub and introduced its first official plugin, which flags information in Claude’s answers that a user might have missed. The key trade-off is that Mods run with the user’s permissions and are not sandboxed.
