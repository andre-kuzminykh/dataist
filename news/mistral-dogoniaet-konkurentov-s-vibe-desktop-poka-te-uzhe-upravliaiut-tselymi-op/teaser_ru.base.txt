Mistral выпустила настольное приложение для ИИ-агента Vibe, ранее известного как Le Chat. Через него можно запускать несколько задач одновременно и наблюдать за их выполнением. Приложение объединяет локальные возможности Vibe CLI и облачные сессии Vibe Code Web: агент работает с локальным репозиторием или в облачной песочнице, а Git worktrees разделяют параллельные задачи внутри одного проекта. Vibe Desktop доступно для macOS и Windows; версию для Linux планируют выпустить позже.
