## Where Mods run

Mods run with the user’s permissions, and Anthropic says they are not isolated in a sandbox. The company recommends installing them only from trusted sources. Organizations can restrict which Mods are allowed to load.

Support varies by interface:

- Command-line app: supported
- Desktop app: supported
- VS Code extension: partial support

## The first official plugin

Anthropic’s first official plugin is called “You Should Know.” It runs a separate agent that monitors Claude’s answers and sends a “Worth noting” message when it spots important information the user may have missed.

Enable it with:

```Command
/plugin enable cc-plugin-you-should-know@builtin
```

The more interesting question is how much control users and organizations get over what a separate agent considers important. I think the permission model makes that question especially consequential: Mods can alter the tool from within, but they are not contained in a sandbox.
