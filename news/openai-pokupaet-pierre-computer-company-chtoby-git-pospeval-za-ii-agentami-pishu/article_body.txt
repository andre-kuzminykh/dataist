# OpenAI покупает стартап, чьи инструменты уже работают в Codex

## Инструменты для работы с кодом

Pierre Computer Company создала несколько инструментов, которыми пользуются в Codex:

- **Trees** помогает быстро перемещаться по файлам проекта.
- **Diffs** показывает изменения в коде и позволяет исправлять ошибки прямо в окне сравнения.
- **Highlights** подсвечивает синтаксис в реальном времени, пока разработчик печатает или ИИ-агент генерирует код.
- **Code Storage** хранит код и отслеживает его историю с помощью Git.

OpenAI объясняет покупку тем, что Git-процессы должны лучше работать в условиях, когда разработчики и ИИ-агенты пишут код одновременно. По мере того как агенты берут на себя больше задач параллельно, инструменты для работы с Git должны справляться с такой нагрузкой.

OpenAI уже использует собственную систему управления версиями Pando, созданную для разработчиков и ИИ-агентов. Проекты Pierre с открытым исходным кодом сохранят этот статус. Сделка пока ожидает одобрения регулирующих органов.

По оценке Dataist, OpenAI усиливает инструменты вокруг Codex и расширяет собственную инфраструктуру для совместной работы людей и ИИ-агентов с кодом. При этом проекты Pierre останутся открытыми, а завершение сделки зависит от решения регуляторов.
