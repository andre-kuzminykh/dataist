# Meta представила мультимодальную модель Muse Spark 1.1

Meta Superintelligence Labs выпустила Muse Spark 1.1 — мультимодальную модель рассуждения для задач с ИИ-агентами. По сравнению с Muse Spark она заметно улучшила работу с инструментами и компьютером, программирование и мультимодальное понимание, а также получила контекстное окно на 1 млн токенов и поддержку мультиагентных систем. Модель уже доступна в режиме «Рассуждение» в приложении Meta ИИ и на meta.ai. Для разработчиков запустили публичную предварительную версию Meta Model API.

## Что умеет Muse Spark 1.1

Muse Spark 1.1 предназначена для персональных задач с ИИ-агентами, где нужно планировать действия и координировать работу через разные внешние приложения и сервисы. Модель умеет без дополнительного обучения работать с новыми встроенными инструментами, MCP-серверами и пользовательскими навыками.

Сложные проекты она выполняет быстрее, чем Muse Spark: модель обучали координировать мультиагентные системы и сокращать общее время выполнения. В роли главного агента она собирает контекст, составляет план и распределяет работу между параллельными подагентами. В роли подагента — придерживается поставленной задачи, учитывает доступные инструменты и понимает, когда нужно передать управление главному агенту.

Модель может самостоятельно управлять контекстным окном размером 1 млн токенов. Она запоминает выполненные действия, извлекает сведения из давно завершённых этапов и сжимает контекст так, чтобы сохранить критически важные шаги для дальнейшей работы.

Muse Spark 1.1 рассчитана на сценарии работы с компьютером, которые проходят через несколько приложений, а данные в них меняются по ходу задачи. Она сохраняет контекст в продолжительных сессиях, подстраивается под новые требования и осваивает незнакомые интерфейсы с минимальным участием человека.

Модель выбирает между автоматизацией и прямым взаимодействием с интерфейсом. Если быстрее написать программу, она пишет программу; если проще нажать нужную кнопку, работает через интерфейс; на каждом этапе также может создавать последовательности действий пакетами.

В примере с организацией званого ужина модель замечает появившиеся изменения при оформлении заказа на еду и сама вносит необходимые обновления.

## Программирование

В задачах на реальных больших и сложных кодовых базах Muse Spark 1.1 заметно улучшила результаты. Она умеет находить и исправлять сложные ошибки, добавлять функции в корпоративные системы и выполнять масштабные миграции кода. В сценариях вроде создания веб-приложений и сквозных систем вопросов и ответов модель показывает существенный прирост по сравнению с первой версией.

Модель обучали адаптироваться к разным оболочкам и стабильно работать со сложными многошаговыми сценариями. Muse Spark 1.1 поддерживает распространённые возможности окружений для агентов программирования: режим планирования, привязку к цели, делегирование подагентам и сжатие контекста.

В демонстрации отладки в OpenCode модель создаёт веб-приложение с чатом, автоматически делает снимки экрана, находит видимые пользователю ошибки, связывает их с соответствующими участками кода, вносит исправления и проверяет результат. В этом сценарии она объединяет программирование, мультимодальное понимание и вызов инструментов.

Разработчики и исследователи Meta уже используют Muse Spark 1.1 каждый день. Во внутреннем бенчмарке Meta для программирования модель заметно опережает Muse Spark и конкурирует с ведущими альтернативами.

Исследователи также автоматизируют с её помощью задачи по разработке и оценке моделей.

В другой демонстрации, созданной в OpenCode на основе оценки DeepSWE, Muse Spark 1.1 проверяет себя на части задач DeepSWE с разными уровнями рассуждения, а затем строит информационную панель с анализом результатов.

## Мультимодальные задачи

Помимо программирования и работы с ИИ-агентами, Muse Spark 1.1 предназначена для восприятия, мультимодального рассуждения и использования инструментов. Она может взаимодействовать с реальными средами и выдавать результаты, связанные с наблюдаемыми данными. Среди её сценариев — создание визуальных артефактов по описанию, подробные описания изображений и видео, а также выполнение мультимодальных процессов с ИИ-агентами.

Мультимодальные возможности особенно полезны там, где восприятие и действие должны идти одновременно. Модель анализирует изображение и звук, сохраняет детали на протяжении длинного процесса и использует их, когда работает с компьютером от имени пользователя.

В примере с агентом для Facebook Marketplace Muse Spark 1.1 получает видео, снятое на смартфон, выбирает из него подходящие фотографии, анализирует товар, открывает браузер пользователя и самостоятельно создаёт объявление на Facebook Marketplace.

## Проверка безопасности

Перед выпуском Meta провела расширенные проверки безопасности в соответствии с рамкой масштабирования ИИ. Эта рамка определяет процедуры оценки, модели угроз и пороги развертывания для наиболее передовых моделей компании.

В категориях передовых рисков — химические и биологические угрозы, кибербезопасность и потеря контроля — Muse Spark 1.1, согласно оценкам Meta, укладывается в безопасные пределы. Модель устойчива к прямым попыткам обхода ограничений, атакам через ненадёжные данные, внедрению запросов и атакам через запрос разработчика. В компании также сообщают о более высокой устойчивости к атакам, меньшем числе галлюцинаций и сниженной склонности соглашаться с пользователем любой ценой.

Полная информация о безопасности Muse Spark 1.1 опубликована в отчёте об оценке.

## Meta Model API

Впервые разработчики могут создавать приложения на базе Muse Spark 1.1 через новую Meta Model API, которая пока работает в режиме публичного предварительного доступа.

Ранние партнёры Meta называют модель полноценной основой для ИИ-агентов: она сочетает длинный контекст, программирование и рассуждение и рассчитана на крупные рабочие нагрузки с ИИ-агентами.

Партнёры отдельно отмечают сочетание контекста на миллион токенов, поддержки изображений, видео и PDF, встроенного поиска с цитатами, рассуждения, программирования, структурированного вывода и параллельного вызова инструментов. API при этом совместима с OpenAI API.

В Cline считают, что Muse Spark 1.1 подходит для серьёзных задач по программированию с ИИ-агентами благодаря работе с инструментами и стоимости, которая позволяет запускать такие нагрузки в большом масштабе.

По словам Yashodha Bhavnani, вице-президента по продуктам ИИ в Box, на корпоративном наборе задач Box модель показала возможности, сопоставимые с ведущими передовыми моделями. Она также подходит для структурированных процедурных процессов в профессиональных услугах, государственном секторе и промышленности.

Ещё один партнёр, разработчики OpenClaw, отдельно отметили скорость и возможности Muse Spark 1.1 для запуска ИИ-агентов.

Meta сообщила, что продолжает обучать более производительные модели и позже расскажет о следующих результатах.
