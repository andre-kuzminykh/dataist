OpenAI’s Decisions API points to a cheaper way to constrain AI agents: ask a model to choose from a fixed set of options rather than generate an open-ended response. The limited-preview service, described by Sam Altman at Dev Day, resembles Jev, a fast, low-cost model from TypeSafe AI. The overlap matters because checking an agent’s actions can be costly with a large language model—and a cheaper check could make it practical to review every action.
