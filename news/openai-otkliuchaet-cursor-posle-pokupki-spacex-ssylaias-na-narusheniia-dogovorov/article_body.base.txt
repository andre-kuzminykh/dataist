# OpenAI разрывает договор с Cursor после сделки SpaceX

Anthropic использует решение OpenAI, чтобы представить себя более надёжным партнёром для Cursor: сооснователь компании Том Браун заявил, что сервис доверяет Anthropic ещё со времён Sonnet 3.5 и что компания продолжит наращивать вычислительные мощности для моделей Claude в Cursor. OpenAI тем временем расторгает договор с Cursor после приобретения сервиса SpaceX. Доступ к моделям GPT через собственные ключи OpenAI сохранится, а прекращение договора вступит в силу 12 ноября 2026 года. Причина — история компаний Илона Маска с нарушением договоров.

Anthropic использует решение OpenAI, чтобы заявить о своей надёжности как партнёра. Том Браун, сооснователь Anthropic и директор по вычислительным ресурсам, написал в социальной сети X, что Cursor остаётся доверенным партнёром компании со времён Sonnet 3.5. По его словам, Anthropic продолжит увеличивать вычислительные мощности для моделей Claude, доступных в Cursor.

В этом есть определённая ирония: сама Anthropic уже не раз отзывала доступ к API у партнёров. В частности, компания заблокировала Windsurf после сообщений о его планируемой продаже OpenAI, а позже закрыла доступ самой OpenAI из-за несанкционированного использования Claude в бенчмарках.

OpenAI прекращает сотрудничество с Cursor после того, как SpaceX приобрела сервис. Компания объясняет решение тем, что предприятия Илона Маска неоднократно нарушали условия договоров.

OpenAI объявила, что расторгнет договор с Cursor <strong>12 ноября 2026 года</strong>. Это максимальный срок уведомления, предусмотренный договором: в нём есть пункт, который позволяет OpenAI в течение ограниченного периода прекратить соглашение после смены владельца. Именно приобретение Cursor компанией SpaceX запустило этот механизм. Теперь OpenAI заявляет, что не может быть уверена в соблюдении SpaceX условий использования.

Представитель OpenAI Тибо Соттьо объяснил решение вопросом доверия. Пользователи Cursor по-прежнему смогут обращаться к моделям GPT через собственные ключи OpenAI, а доступ через расширения OpenAI для среды разработки Cursor сохранится. Соттьо отдельно подчеркнул, что мера направлена именно против Илона Маска, а не против рынка инструментов для программирования и их разработчиков.

Приостановка сотрудничества стала очередным эпизодом многолетнего конфликта Маска и OpenAI, который уже доходил до суда. OpenAI обвиняет Маска в нарушении договоров после покупки Twitter и в попытке получить данные компании. По лицензионному соглашению Twitter предоставлял OpenAI полный поток публикаций примерно за <strong>2 млн долларов в год</strong> для обучения ChatGPT. Узнав об условиях сделки в декабре 2022 года, Маск решил, что цена слишком низкая, и перекрыл OpenAI доступ.

Во время судебного разбирательства Маск также признал, что использовал данные моделей других ИИ-лабораторий для обучения собственных моделей Grok. Такая практика называется дистилляцией и тоже нарушает условия OpenAI.

OpenAI связывает ситуацию и с вопросами безопасности. В компании заявляют, что с появлением модели Astra, которой приписывают расширенные возможности в сфере кибербезопасности, требуется новый уровень ответственности и контроля за соблюдением партнёрами условий использования.

Сооснователь Cursor Майкл Труэлл быстро ответил, что модели OpenAI составляли лишь около <strong>5%</strong> всего объёма обращений к ИИ-системам Cursor. Компания ведёт переговоры с OpenAI, чтобы найти решение. Труэлл напомнил, что Cursor был одним из первых пользователей OpenAI, много лет тесно работал с её командой и рассчитывал на платформу как на нейтральную инфраструктуру для своей деятельности.

OpenAI уже сталкивалась с аналогичным решением со стороны Anthropic. В июне 2025 года Anthropic закрыла инструменту для программирования Windsurf доступ к моделям Claude после сообщений о намерении OpenAI приобрести Windsurf. В августе 2025 года ситуация изменилась: Anthropic отозвала доступ к API у OpenAI, поскольку команды компании, предположительно, использовали Claude для внутренних бенчмарков перед запуском GPT-5.
