## What WebMCP can do

The new tools are `get_checkout`, `update_checkout` and `complete_checkout`. Shopify says they let an agent inspect an order, make changes and complete the purchase with the buyer’s permission, without screenshots or scraping data from web pages.

Shopify is making the feature available to eligible merchants, according to Gil Greenberg, the company’s senior product manager responsible for agentic commerce, who announced it on X.

The browser-based tools sit alongside Shopify’s hosted MCP server, which lets agents interact with the platform server to server. Both approaches use Shopify’s Universal Commerce Protocol (UCP), a shared way to find products, create carts and check out.

- <strong>Hosted MCP:</strong> agents connect directly to Shopify.
- <strong>WebMCP:</strong> agents work in the shopper’s browser.

Shopify says browser agents should use WebMCP on product and checkout pages instead of parsing their HTML. The tools provide structured interfaces for product information, required disclosures and handoffs.

## The missing test

Muse and Instinct already have direct Shopify partnerships for agentic commerce. Shopify announced its partnership with Instinct on the same day as the WebMCP update.

I think the more consequential question is not whether an agent can reach checkout, but how much control the buyer retains once it gets there. Shopify says the agent needs permission to submit the transaction, but the announcement does not describe how that permission is requested or how a buyer can review the changes before approval.

That leaves WebMCP’s promise resting on a narrow distinction: agents get a structured interface, while the buyer remains the one authorizing the purchase. If that boundary is clear in practice, Shopify can make agent-driven checkout easier without making it less legible to the person paying.
