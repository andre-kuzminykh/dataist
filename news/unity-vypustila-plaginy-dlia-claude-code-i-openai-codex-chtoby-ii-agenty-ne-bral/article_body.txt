# Unity выпустила плагины для Claude Code и OpenAI Codex

## Навыки для Unity

Unity Technologies разработала плагины для Claude Code и Codex — агентов для программирования от Anthropic и OpenAI. Их навыки создают и поддерживают команды Unity.

Версия для Codex получила 31 навык, в том числе для:

- пользовательских интерфейсов;
- двумерной графики;
- пайплайна рендеринга URP;
- работы со звуком;
- навигации;
- физики;
- внутриигровых покупок;
- многопользовательских игр;
- локализации.

Один из навыков настраивает новый проект вместе с редактором, системой контроля версий и пакетами. Другой переносит старые проекты на URP.

По данным Unity, универсальные ИИ-агенты часто обращаются к сообщениям на форумах и учебникам для устаревших версий движка. Код из таких материалов может собираться, но при этом работать не так, как задумано.

Плагины поддерживают Unity 6 и более новые версии. В Codex их можно установить одним нажатием в каталоге плагинов, а в Claude Code — через `npm`.

## Модели управляют программами

Языковые модели всё чаще управляют сложными программами, особенно в разработке игр. Одним из первых приложений, которыми можно было управлять через языковую модель с помощью протокола Model Context Protocol, стал трёхмерный редактор Blender.

Теперь такие модели, как Know3D, формируют трёхмерные объекты по текстовым командам. World Labs с помощью Atlas создаёт целые трёхмерные сцены всего по нескольким изображениям.
