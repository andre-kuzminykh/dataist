# OpenAI расширила Codex и API: добавила проверки безопасности и быстрые решения

## Общие облачные среды ускоряют запуск задач Codex

По данным OpenAI, Codex теперь работает на компьютере пользователя, с телефона и в облаке — с любого устройства. В мае компания уже добавила управление Codex через мобильное приложение ChatGPT. Новинка — повторно используемые среды разработки, которые должны ускорить запуск задач. Команды могут делиться настройками и разрешениями, заранее одобренными для работы. Облачный Codex доступен в планах Plus, Pro, Business, Enterprise, Edu и Healthcare.

OpenAI также переработала интерфейс командной строки Codex. Теперь пользователи могут запускать задачи и управлять ими голосом. Новый раздел `/agents` упрощает делегирование и позволяет видеть несколько задач одновременно. Компания улучшила редактирование промтов, возобновление сессий и работу с рабочими деревьями Git, а также обновила оформление терминала. Новая версия доступна во всех планах.

## Codex проверяет код и ищет уязвимости

В настольном приложении ChatGPT появился отдельный интерфейс для проверки изменений сразу в нескольких проектах. Разработчики могут читать сводки, изучать различия в коде и спрашивать Codex о возможных проблемах, прежде чем оставить отзыв к запросу на слияние в GitHub или GitLab. При автоматической проверке Codex делает первый проход в облаке, пока разработчик отошёл от компьютера. Функция доступна во всех планах.

Codex Security Cloud предназначен для команд по безопасности. Он проверяет целые репозитории GitHub по запросу или расписанию и отслеживает новые коммиты. Codex анализирует найденные проблемы, отбрасывает дубликаты и готовит исправления в облаке, даже если ноутбук выключен. В июле OpenAI выпустила Codex Security CLI — инструмент с открытым исходным кодом, который проверяет репозитории из командной строки и в пайплайнах CI/CD.

Пользователи облачной версии также получают доступ к моделям Daybreak Blue без отдельной заявки. Daybreak Blue — защитное направление программы OpenAI по кибербезопасности; модели рассчитаны, например, на анализ вредоносных программ. Раньше для доступа требовалось, среди прочего, подтвердить личность. Codex Security Cloud доступен в планах Pro, Business, Enterprise и Edu — в настольной и веб-версиях.

## Агенты через API теперь могут сами работать с программами

Agents API находится в открытом бета-тестировании с 11 сентября и работает на той же инфраструктуре, что Codex и ChatGPT. Новая функция Computer Use позволяет агентам самостоятельно управлять программами, чтобы выполнять задачи. В Codex и ChatGPT на macOS она появилась в апреле, а на Windows 11 — в мае.

По словам OpenAI, в API теперь также доступны мультиагентные функции Codex, поиск инструментов и автоматическое сокращение длинного контекста.

В апреле AWS и OpenAI объявили о предварительной версии Bedrock Managed Agents с ограниченным доступом. Теперь платформа включает основные функции Agents API, позволяет адаптировать их для AWS и напрямую подключается к ресурсам AWS. Разработчики могут создавать ИИ-агентов OpenAI, которые работают целиком на AWS.

## OpenAI выпускает API для быстрых решений

С Decisions API OpenAI выходит в область так называемых моделей System One. В середине сентября стартап TypeSafe AI Диого Алмейды представил модель Jev, и запуск бывшего исследователя OpenAI вызвал волну интереса среди разработчиков. Перспективным выглядит сочетание более сильной модели-координатора с быстрой моделью для принятия решений. Например, один агент для Minecraft поручает GPT-6 Astra составлять цели и маршрутные точки, а Jev выбирает отдельные действия — добывать ресурсы, создавать предметы или сражаться.

Для Decisions API OpenAI использует версию своей недорогой модели GPT-6 Luna. Разработчик задаёт вопросы с ограниченным набором заранее определённых ответов, передаёт контекст в виде текста или изображений и получает ответ. API можно использовать для классификации контента, перенаправления запросов или выбора следующего шага агента. Сначала сервис выйдет в предварительной версии с ограниченным доступом; широкую доступность ожидают в ближайшие дни.

## Ultrafast ускоряет работу, но стоит в шесть раз дороже

По данным OpenAI, премиальный режим Ultrafast ускоряет генерацию токенов в Codex до восьми раз — до 300 токенов в секунду. В API скорость может быть выше в шесть раз, а цена Ultrafast составляет шесть стандартных тарифов. Для GPT-6 Astra это $60 за миллион входных токенов и $300 за миллион выходных.

Режим Fast для Astra стоит вдвое дороже стандартного и работает в 2,5 раза быстрее. GPT-5.3-Codex-Spark была значительно быстрее — более 1 000 токенов в секунду на оборудовании Cerebras, — но это модель меньшего размера с более низкими результатами на бенчмарках.

GPT-6 Astra Ultrafast уже доступна через API. Она также появилась в ChatGPT Work и Codex для корпоративных клиентов и подписчиков нового плана Pro 500. Подписка стоит $500 и, по обещанию OpenAI, даст наибольший лимит использования среди всех планов, хотя точные пределы компания не раскрыла.

В существующем плане Pro за $200 лимит использования ChatGPT Work и Codex теперь составит десятикратный объём Plus вместо двадцатикратного. Недельный лимит сообщений GPT-6 Pro в чате уменьшится с 200 до 100. Действующим подписчикам на переходный период сохранят прежние ограничения и выдадут разовый кредит.

Новая GPT-6.1 Sol стоит в API столько же, сколько предшественница: $2 за миллион входных токенов и $10 за миллион выходных. Версию Ultrafast ожидают в ближайшие дни.
