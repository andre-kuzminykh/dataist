# Nvidia превращает домашнюю сеть в мини-центр для локального ИИ

PAIR автоматически находит совместимые устройства в сети и защищает обмен данными между ними с помощью шифрования MTLS. Инструмент поддерживает:

- GeForce RTX 20-й серии и новее;
- рабочие станции RTX Pro;
- DGX Spark;
- компьютеры на чипах Apple, начиная с M4.

[VIDEO:0]

Бета-версия PAIR доступна для Windows, macOS и Linux. Инструмент продолжает стратегию NVIDIA по более тесной интеграции открытых ИИ-инструментов с собственным оборудованием — такой же подход отражает покупка Hugging Face за $12,9 млрд.
