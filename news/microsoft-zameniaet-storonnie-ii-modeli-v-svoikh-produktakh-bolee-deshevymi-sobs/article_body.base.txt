# Microsoft выводит на рынок семь собственных моделей ИИ для бизнеса

## Модели для программирования и рабочих задач

Microsoft выпустила все семь моделей одновременно, а не распределила запуск на год: так же компания поступила на конференции Build в июне. Основная ставка — на стоимость при заданном уровне качества: по словам Microsoft, расходы клиентов на токены быстро растут, когда ИИ-агенты работают круглосуточно. Модели для программирования рассчитаны на повседневные корпоративные задачи, но пока не оптимизированы для фундаментальных исследований и длительных задач с ИИ-агентами.

MAI Code 2 в среднем набирает 98% от результата GPT-6.1 Sol на четырёх бенчмарках при 40% его стоимости. По сравнению с Claude Opus 5.5 результат составляет 96%, а цена — 5%. Microsoft проверяла модель на DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas и FrontierCode v1.1. Три теста проходили на внутренней платформе MSBench через GitHub Copilot CLI, без субагентов. При расчёте стоимости Microsoft учитывает рекламную скидку 50% на собственную модель.

В слепых сравнениях интерфейсов, игр, визуализаций данных и графики SVG оценщики предпочитали результат MAI Code 2 результату GPT-6 Sol в 64% случаев, сообщает Microsoft.

MAI Code 2 Flash — преемница MAI-Code-1.1-Flash — предназначена для объяснения кода, точечных изменений и обычных исправлений. По заявлению компании, она сопоставима с GPT-6 Luna и Claude Haiku 5.5, а стоит соответственно 65% и 20% от их цены.

На основе модели Flash Microsoft создала MAI Work Flash для Microsoft 365 и Fabric IQ. На внутренних бенчмарках Excel и PowerPoint она сравнялась с GPT-6 Luna. В Word модель показала результат на уровне GPT-6.1 Sol, используя примерно на 42% меньше входных токенов. Для создания запросов DAX в Power BI она превзошла GPT-5.6 Sol, GPT-6 Astra и Opus 5.5.

В GitHub Copilot рекламная цена MAI Code 2 до 17 мая 2027 года составляет $0,50 за миллион входных токенов и $2,50 за миллион выходных. После этой даты цена вырастет до $1 и $5 соответственно. Для MAI Code 2 Flash ставки до того же срока — $0,05 за миллион входных токенов и $0,25 за миллион выходных, затем они составят $0,10 и $0,50.

## Кибербезопасность и проверка бенчмарка

В бенчмарке уязвимостей CyberGym-E2E MAI Cyber 2 Flash решает 92,3% задач, тогда как GPT-6 Astra — 91,5%. При этом GPT-6 Astra требует вдвое большего бюджета на рассуждение. Одна задача обходится Microsoft менее чем в 2% от стоимости задачи на модели OpenAI, а цена токенов примерно в сто раз ниже. В WebExploitBench результат MAI Cyber 2 Flash — 40,4%, выше, чем у GPT-5.6 Cyber с 38,4%.

При проверке Microsoft обнаружила, что около 10% из примерно 900 задач CyberGym опираются на те же проекты с открытым исходным кодом и отчёты об уязвимостях, что и части обучающих данных компании. Эталонные решения в обучение, по заявлению Microsoft, не попадали. Тем не менее компания исключила эти задачи из оценки всех моделей и сравнила результаты на оставшихся.

Сравнения с GPT-6 Cyber пока нет: эта модель доступна только отдельным клиентам. Для бенчмарков ИИ-агентов с инструментами, по словам Microsoft, ещё нужны дополнительные меры безопасности. Компания планирует опубликовать результаты в ближайшие недели.

Контекстное окно MAI Cyber 2 Flash вмещает миллион токенов — в четыре раза больше, чем у MAI Cyber 1.1 Flash. Выходные токены стоят на 86% меньше, чем у предшественницы. По данным пресс-релиза Microsoft, модели MAI Cyber уже обрабатывают почти 40% проверок на платформе безопасности MDASH.

MAI Cyber 2 Flash стоит $0,10 за миллион входных токенов и $0,50 за миллион выходных. Для GPT-6 Astra соответствующие цены — $10 и $50. В CyberGym-E2E стоимость одной задачи составляет $0,45 против $34,38.

## Модель решений на основе Gemma

Microsoft-Decision-1.1 распределяет запросы, классифицирует и расставляет их по приоритету, а также управляет рабочими процессами. Модель выбирает из одобренных разработчиками действий и выдаёт калиброванные оценки уверенности. Если уверенность низкая, приложение может передать решение дальше, вместо того чтобы действовать наугад. При неполных данных модель должна воздерживаться от ответа.

В основе модели — Gemma 4 26B A4B, модель со смесью экспертов от Google. Предыдущая версия использовала Qwen3.5-9B. Microsoft обучала новую модель с помощью обучения с учителем и обучения с подкреплением на сотнях синтетических и лицензированных наборов данных. Работает она на собственной системе инференса Microsoft.

В Decision Index v2.1 от Artificial Analysis Microsoft-Decision-1.1 набрала 68 баллов — на шесть больше предшественницы и выше, чем Jev 1.14, Gemini Decision 1 и GPT-6 Luna (Decisions). Кроме того, Microsoft проверила модель на 102 внутренних бенчмарках с более чем 385 000 вопросов. Среди восьми моделей для принятия решений она показала наивысшую среднюю точность.

Модель теперь принимает изображения, в том числе снимки экрана. В Copilot она определяет, направить запрос в Copilot или Cowork. Microsoft утверждает, что модель работает с точностью большой языковой модели, но в 2,2 раза быстрее и в 4,4 раза дешевле. В Cowork функция Auto выбирает, сколько усилий на рассуждение выделить задаче.

Цена Microsoft-Decision-1.1 — $0,042 за миллион входных токенов, или $0,05 в зоне обработки данных ЕС. Выходные токены бесплатны.

Другую специализированную модель, Microsoft-Retriever-1, Microsoft описала в сборнике новостей Ignite. Она находит нужные сведения в корпоративных документах для ИИ-агентов в Foundry IQ. Вместо одного поиска модель планирует запросы, проверяет результаты и делает дополнительные запросы, пока не соберёт достаточно материалов для обоснованного ответа. Microsoft заявляет, что такой подход быстрее и эффективнее прежних методов. Retriever-1 запускается в предварительной версии. Model Router в Foundry также теперь автоматически выбирает модели из расширенного набора.

## Редактирование изображений и речь

MAI Image 2.7 занимает первое место в рейтинге редактирования изображений Artificial Analysis: 1 215 баллов Эло на основе 5 478 голосов. Это на четыре балла выше результата GPT Image 2.6 Sunburst (max), а стоимость — в пять раз ниже. В создании изображений по текстовому описанию модель занимает в этом рейтинге четвёртое место. Тысяча изображений, созданных с помощью MAI Image 2.7, стоит около $35, версия Flash — около $10.

Модель умеет менять цвет, материал или положение отдельных объектов, не затрагивая остальную часть изображения, и создавать прозрачный фон. Меньшая версия Flash стоит менее трети от полной и используется в Canvas — новом редакторе изображений в MAI Labs. С июня MAI Image установлена по умолчанию в Bing Image Creator. По данным Microsoft, с моделью также работают Adobe, Figma Weave, Minute (Sports Illustrated), Wirestock и Manus.

[FIGURE:3]

MAI Realtime 1 — первая речевая модель Microsoft, которая преобразует речь в речь. Она рассчитана на диалоги с перебиваниями, умеет дожидаться окончания реплики и распознавать запросы при фоновом шуме. Для сложных задач модель переключается на более мощную систему рассуждения: за неё платят по числу токенов, тогда как базовая ставка начисляется за минуты аудио. На Big Bench Audio, τ-Voice и тестах с Dynamics 365 модель, по заявлению Microsoft, превосходит GPT Realtime 2.1.

MAI Realtime 1 совместима с OpenAI Realtime API, поэтому существующие голосовые приложения могут перейти на неё. Модель тестируют Agoda и Reservations.ai. Microsoft также планирует добавить её в Dynamics 365 Contact Center и Dragon Copilot: медсёстры смогут использовать систему для тренировки разговоров с пациентами.

Dragon Copilot Transcribe на базе MAI Transcribe 2 теперь обрабатывает все записи разговоров врачей с пациентами в Dragon Copilot — 10 миллионов разговоров в месяц, сообщает Microsoft. В многоязычных рабочих процессах число ошибок снижается вдвое. Для собственных больших моделей Microsoft теперь использует Maia 200, второе поколение ускорителя ИИ. По данным компании, он обеспечивает в 1,7 раза больше токенов на ватт.

Одна минута аудио в MAI Realtime 1 стоит один цент США. Использование системы рассуждения оплачивается отдельно: $1 за миллион входных токенов и $5 за миллион выходных.

## Настройка моделей и доступность

С помощью MAI Licensed Weights компании смогут дообучать модели MAI на собственных данных и запускать их в своей среде Azure. Данные и настройки останутся у клиента. Microsoft заявляет, что использует их для обучения собственных моделей только с явного согласия.

Компания противопоставляет это предложение моделям с открытыми весами: по её оценке, организациям сложно проверить их происхождение и поведение. В качестве примера Microsoft приводит американского оператора AT&T. По имеющимся данным, настроенная модель для анализа работы сетей 5G превзошла GPT-6.1 Sol на стандартных задачах и обошлась примерно в пятьдесят раз дешевле. Дату запуска и цены Microsoft пока не объявила. Предложение должно появиться «в ближайшее время» в рамках программы Frontier Company; заинтересованным компаниям предлагают обращаться к представителям Microsoft.

MAI Code 2 и Code 2 Flash доступны в GitHub Copilot. Code 2 Flash также можно тестировать в ограниченной предварительной версии в Foundry. В дальнейшем модели должны появиться в OpenRouter, Vercel, Hermes, Open Code и Kilo.

MAI Image 2.7 и Flash доступны в публичной предварительной версии в Foundry, а также на fal, Genspark, OpenRouter и Vercel. Decision 1.1 доступна всем пользователям Foundry, на OpenRouter и через ИИ Gateway от Vercel. MAI Realtime 1 можно опробовать в MAI Labs; в Foundry она доступна в предварительной версии бесплатно до начала публичного тестирования. MAI Cyber 2 Flash предлагается только в продуктах Microsoft для безопасности. Начиная с середины декабря для подходящих клиентов MDASH автоматически заменит ею существующую модель в профиле MAI.

В апреле Microsoft и OpenAI пересмотрели условия партнёрства. OpenAI получила возможность продавать свои продукты через любого облачного провайдера, однако Azure остаётся её основным облачным партнёром. Неисключительная лицензия Microsoft на модели и продукты OpenAI действует до 2032 года.

По оценке Dataist, Microsoft строит линейку собственных моделей вокруг расходов на постоянную работу ИИ-агентов и уже предлагает цены, заметно ниже стоимости моделей OpenAI в отдельных сценариях. При этом часть сравнений основана на внутренних бенчмарках Microsoft, а результаты проверки ИИ-агентов с инструментами компания ещё не опубликовала. Возможность настраивать модели на данных заказчика расширяет предложение для бизнеса, но сроки запуска и цены MAI Licensed Weights пока неизвестны.
