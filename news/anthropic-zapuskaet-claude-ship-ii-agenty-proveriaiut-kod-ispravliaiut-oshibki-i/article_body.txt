# Anthropic запускает Claude Ship для проверки, исправления и утверждения кода

## От проверки к утверждению

Claude Ship продолжает работу Anthropic над инструментами для программирования: теперь компания предлагает не только помощь в написании кода, но и автоматизацию этапов после создания запроса на слияние — PR. Системы для программирования уже умели проверять код, а нововведение Claude Ship — агент, который может утверждать изменения по правилам, заданным командой.

Инструменты для программирования всё чаще создают большие объёмы кода, и его проверка и утверждение могут замедлять выпуск изменений. Anthropic предлагает передать часть этой работы ИИ-агентам. Компания поясняет, что многим командам привычно, когда каждое изменение утверждает человек, но при активном использовании агентов такой процесс сложнее поддерживать. В самой команде Claude, по словам Anthropic, Claude пишет большую часть кода, и компания хотела ускорить работу после создания PR.

Claude Ship выходит в бета-версии: ранние пользователи могут поручить ему проверку PR, а затем определить, какие изменения готовы к слиянию.

## Три инструмента в наборе

В Claude Ship входят Code Review и два новых агента:

- **Code Review** — инструмент для проверки кода, уже доступный всем пользователям.
- **PR Steward** — устраняет проблемы, включая сбои проверок CI, конфликты слияния и замечания Code Review. После каждого отправленного изменения агент сообщает, что исправил и как при необходимости отменить его правки.
- **Claude Approvals** — применяет правила утверждения, которые команда записывает в файл репозитория. Правила можно сформулировать на естественном языке; они могут учитывать результаты Code Review и классификаторы самой компании.

Code Review доступен всем пользователям, а PR Steward и Claude Approvals пока находятся в бета-версии.

## Контроль остаётся у команды

Поскольку продукт ещё тестируется, Anthropic советует сначала включить утверждение в режиме наблюдения — так команда сможет оценивать работу системы, не передавая ей полномочия сразу. Для осторожного запуска можно ограничить использование одним репозиторием и установить месячный лимит расходов.

Команды также выбирают, где запускается Claude Ship, какой режим проверки использовать — Quick, Standard или Deep — и какие изменения отправлять человеку на решение. Сервис доступен для репозиториев на GitHub в планах Claude Team и Enterprise.

По оценке Dataist, Claude Ship переносит часть решений о готовности кода с человека на правила, заданные командой. Поэтому режим наблюдения, ограничение числа репозиториев и передача спорных изменений человеку — важные меры контроля, пока PR Steward и Claude Approvals остаются в бета-версии.
