# Google выпустила компактную модель для поиска по тексту, изображениям и видео

[FIGURE:0]

Модель работает локально, без ключа API. Один запрос занимает около 20–70 миллисекунд при запуске через WebGPU в браузере. Для работы ей требуется около 191 МБ оперативной памяти, а объём локального хранилища векторной базы данных может сократиться до шести раз. Для задач только с текстом достаточно версии на 270 млн параметров.

В сочетании с небольшими открытыми моделями, например Gemma 4, EmbeddingGemma 2 позволяет запускать офлайн-приложения с RAG, не отправляя данные на внешние серверы. Веса модели доступны на Hugging Face и Kaggle вместе с руководством для разработчиков и документацией.
