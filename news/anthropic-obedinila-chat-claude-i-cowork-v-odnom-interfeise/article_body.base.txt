# Anthropic объединяет Claude и Cowork в одном интерфейсе

## Единое окно для разных задач

Раньше пользователям было трудно понять, какую вкладку выбрать для конкретной работы. Теперь переключаться между вкладками и окнами не нужно: Claude автоматически определяет, куда направить запрос. Anthropic хочет использовать один интерфейс для доступа к разным частям приложения.

В едином окне доступны:

- чат Claude;
- Cowork;
- Artifacts — интерактивное рабочее пространство Claude;
- Claude Design — функция для создания сайтов и прототипов, представленная в апреле.

Авторы материала надеются, что OpenAI воспользуется похожим подходом и исправит интерфейс ChatGPT на разных платформах.

## Презентации и документы

Anthropic добавила отдельные функции для работы с презентациями и документами. Пользователь может попросить ИИ-ассистента:

- создать слайды;
- отредактировать презентацию;
- показать её;
- скачать результат в формате PDF или PowerPoint.

Функция Docs позволяет работать над документом вместе с Claude: создавать разделы, задавать вопросы и оставлять комментарии к готовым частям. Сгенерированные документы и слайды можно отправлять по ссылке, а затем редактировать с телефона.

Задачу можно начать на компьютере, а её выполнение проверять в мобильном приложении.

## Когда появится обновление

Новые возможности в течение ближайших недель начнут получать подписчики тарифов Pro и Max — в веб-версии Claude, настольном и мобильном приложениях. Позже Anthropic планирует добавить их в бесплатный и командный тарифы.

Обновление вышло после улучшения слоя памяти Cowork: он помогает Claude сохранять контекст пользователя между чатами.
