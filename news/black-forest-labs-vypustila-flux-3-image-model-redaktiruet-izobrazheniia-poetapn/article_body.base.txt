# Black Forest Labs выпустила Flux 3 Image с поэтапным редактированием изображений

До 8 октября доступ к API продают со скидкой 50%. Компании могут лицензировать коммерческие веса, чтобы запускать и дообучать модель на собственной инфраструктуре. Версию с открытыми весами обещают выпустить в ближайшие недели. Незадолго до этого Ideogram анонсировала модель для редактирования изображений версии 4.5; её тоже планируют вскоре выпустить с открытыми весами.
