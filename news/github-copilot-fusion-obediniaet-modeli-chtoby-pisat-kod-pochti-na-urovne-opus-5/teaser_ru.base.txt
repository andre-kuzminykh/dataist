GitHub представила Copilot Fusion — систему, которая выбирает модели ИИ и координирует их работу над задачами по разработке ПО. По тестам Artificial Analysis, режим Fusion Max обходился в среднем в $5,59 за задачу против $11,42 у Claude Code с Claude Opus 5.5 — примерно на 51% дешевле. При этом Fusion набрал 60 баллов в агент для программирования Index, всего на два меньше конкурента, и, по данным GitHub, выполнял задачи примерно на 40% быстрее. Отдельная оценка Microsoft о снижении расходов до 77% получена в других тестах и не сопоставима напрямую с результатами Artificial Analysis.
