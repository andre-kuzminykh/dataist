# Anthropic объединяет Claude Cowork с основным чатом

## Claude сам превращает разговор в проект

До сих пор Anthropic разделяла обычные разговоры с Claude и Cowork на два связанных, но разных режима. На веб-сайте, компьютерах и мобильных устройствах оба запускались с одной домашней страницы Claude, однако Cowork нужно было отдельно выбрать переключателем под полем ввода. В боковой панели Claude в Chrome её открытие сразу запускало сессию Cowork.

До среды Cowork был широко доступен в Claude Desktop на платных тарифах, в веб- и мобильных версиях для клиентов Pro, Max и Team, а также в подключённых учётных записях Enterprise. Через боковую панель Claude в Chrome им могли пользоваться подписчики Max и Team, а доступ для Pro постепенно расширялся. Версия для компьютера давала дополнительные возможности: Claude мог напрямую обращаться к локальным файлам и использовать браузер на компьютере пользователя.

Новая схема убирает явный выбор между Chat и Cowork. Согласно разъяснениям Anthropic, по мере обновления конкретной учётной записи переключатель Cowork исчезнет. Если разговор потребует длительной работы, Claude сам переведёт его в нужный режим — пользователю не придётся переносить материалы или начинать отдельную сессию.

Внутреннее поведение Cowork не исчезает. Пользователи, включая компании, которые уже работали с ним, сохранят свои:

- чаты;
- проекты;
- артефакты;
- коннекторы;
- навыки.

Агентные возможности Cowork — длительное выполнение задач, работа с коннекторами и инструментами, разбиение задач на части и продолжение работы, пока пользователя нет рядом, — станут обычной частью работы Claude.

Само название Cowork со временем исчезнет, хотя на переходном этапе пользователи ещё могут его видеть.

Claude Code останется отдельным продуктом. Anthropic уточняет, что он предназначен для разработчиков, которые работают с кодовыми базами из терминала и сред разработки, поэтому в объединение продуктов среды не входит.

## Claude Docs и Slides превращают ответы в рабочие документы

Вторая часть выпуска — переход от генерации ответов к созданию редактируемых рабочих материалов.

Claude Docs запускается в бета-версии. Пользователь может попросить Claude подготовить документ, а затем продолжить совместную работу над ним. Claude умеет писать разделы, задавать вопросы и комментировать варианты, а коллеги могут одновременно редактировать тот же документ. Изначально документы доступны только владельцу, после чего их можно открыть выбранным пользователям или более широко распространить внутри организации.

Название Claude Docs уже использовалось для сайта документации разработчика Anthropic. В сентябре 2025 года компания переименовала его из Anthropic Docs в Claude Docs в рамках объединения бренда Claude. Новый продукт для создания документов не связан с прежним сайтом.

Claude Slides работает по похожей схеме для презентаций. Пользователь просит создать презентацию в обычном разговоре с Claude, редактирует отдельные слайды и показывает результат прямо из сервиса. Это отдельный продукт, не совпадающий с Claude for PowerPoint — существующим дополнением Anthropic для Microsoft PowerPoint, которое работает внутри приложения Microsoft. Claude for PowerPoint получил крупное обновление в марте 2026 года.

Главное отличие Docs и Slides в том, что Anthropic рассматривает их как рабочие документы внутри Claude, а не как файлы, которые создаются только в конце чата. Материалы из Docs, Slides и Design могут находиться по одной ссылке, которой можно поделиться, и оставаться редактируемыми, в том числе с телефона.

Claude Slides и Claude Docs работают в вебе: они открываются по общей ссылке, как Google Документ, а не хранятся только как файл на компьютере.

Anthropic сообщила VentureBeat по электронной почте, что Claude Slides можно скачать в форматах PowerPoint и PDF, а Claude Docs — экспортировать в Microsoft Word и Google Docs. Компания также планирует добавить другие варианты экспорта.

Claude Design, который раньше был отдельной частью продукта, теперь тоже работает внутри разговоров с Claude. Пользователь может попросить создать графику, одностраничный визуальный материал или другой дизайн, а затем самостоятельно менять элементы либо описывать Claude нужные правки.

Для корпоративных клиентов это означает, что Claude должен работать не только с отдельно взятым контентом, созданным ИИ, но и с большей частью пути от запроса до готового результата.

Anthropic приводит пример еженедельного отчёта. Пользователь просит Claude:

- проверить изменения в дата-пайплайне;
- написать отчёт в принятом формате;
- отметить отставание;
- превратить основные выводы в пять слайдов.

Claude может задать уточняющие вопросы, продолжить работу в отсутствие пользователя и вернуть документ и презентацию из одного разговора, сохранив согласованность между ними. Затем задачу можно запланировать на повторный запуск в следующий понедельник.

## Cowork начинался как «Claude Code для остальных задач»

Объединение происходит всего через восемь месяцев после того, как Anthropic представила Cowork в формате исследовательского превью 12 января 2026 года. Изначально возможности продукта были гораздо уже: Cowork появился как функция Claude Max в настольном приложении для macOS и переносил агентный подход Claude Code в нетехнические задачи.

Anthropic фактически взяла архитектуру Claude Code и открыла её людям, которые не работают в терминале. Компания заметила, что разработчики используют Claude Code и для задач, не связанных с разработкой: поиска вариантов для отпуска, создания слайдов, очистки электронной почты и других повседневных дел. Ту же модель делегирования упаковали в графический интерфейс. На момент запуска VentureBeat описывала Cowork как перенос агентных возможностей Claude Code к нетехническим пользователям.

Появление Cowork также стало одним из ранних факторов, повлиявших на дебаты, которые трейдеры и аналитики позже назвали «SaaSpocalypse». При этом было бы преувеличением связывать всё падение рынка программного обеспечения летом 2026 года с январским запуском. Первой публикации Cowork хватило, чтобы усилить уже начавшийся спор о том, смогут ли универсальные ИИ-агенты взять на себя работу, которую раньше выполняли специализированные приложения.

В следующие недели опасения усилились: Anthropic глубже внедряла Claude в корпоративные процессы и выпускала новые специализированные возможности. К концу февраля рыночный нарратив стало трудно отделить от темпа релизов Anthropic. VentureBeat писала, что ServiceNow, Salesforce, Snowflake, Intuit и Thomson Reuters столкнулись с давлением на фоне опасений: более способные ИИ-агенты могут снизить ценность отдельных продуктов SaaS.

Cowork помог запустить и сформулировать рыночный спор 2026 года о том, могут ли универсальные ИИ-агенты выполнять работу, которая прежде велась внутри специализированных SaaS-приложений. Однако последовавший более острый эпизод «SaaSpocalypse» возник не только из-за Cowork. На него повлияли накопившиеся опасения вокруг следующих выпусков Anthropic, специализированных плагинов, возможностей Claude Code и вероятности того, что ИИ-ориентированные рабочие процессы будут проходить сразу через несколько корпоративных систем или заменят их отдельные части.

Поэтому нынешнее изменение выходит за рамки редизайна навигации. Anthropic берёт агентную модель работы, которая изначально была скрыта за отдельным переключателем Cowork, и делает её стандартной архитектурой самого Claude.

## Пользователь по-прежнему управляет самостоятельностью Claude

Отказ от границы между режимами не означает отказа от пользовательского контроля.

По умолчанию Claude запрашивает разрешение перед выполнением действия. Пользователь может настроить его так, чтобы Claude продолжал работу самостоятельно и обращался к нему только тогда, когда потребуется более тщательная проверка. В Cowork уже были разные режимы подтверждения для работы с коннекторами и инструментами, и объединённый продукт сохраняет основной принцип: пользователь сам определяет, насколько самостоятельно должен действовать Claude.

Для организаций это особенно важно, поскольку Claude всё чаще работает сразу с несколькими приложениями и сервисами. Он может:

- читать файлы;
- использовать подключённые сервисы;
- просматривать сайты;
- создавать документы и презентации;
- планировать регулярные задачи.

Anthropic рассчитывает, что пользователю больше не придётся заранее разбираться, какая часть продукта подходит для передачи Claude конкретной задачи.

В новой модели интерфейс становится проще, а внутренняя система — функциональнее: пользователь начинает разговор с Claude, а продукт сам решает, нужен ли ответ, документ, презентация, дизайн или длительный агентный процесс.

Для Anthropic это также изменение первоначального позиционирования Cowork. То, что в январе описывалось как «Claude Code для остальных задач», постепенно становится просто Claude.
