На конференции для разработчиков DevDay 2026 в Сан-Франциско OpenAI представила обновления Codex и платформы ИИ-агентов. Codex получил общие облачные среды разработки, управление задачами голосом и проверку кода в настольном приложении; отдельный сервис сканирует репозитории на уязвимости и готовит исправления. В Agents API появилась функция Computer Use для самостоятельной работы агентов с программами, а Decisions API на базе GPT-6 Luna предназначен для быстрых решений и классификации. Новый тариф Ultrafast ускоряет генерацию токенов, но в API стоит в шесть раз дороже обычного. Он доступен для GPT-6 Astra в корпоративных планах и новой подписке Pro 500 за $500 в месяц.
