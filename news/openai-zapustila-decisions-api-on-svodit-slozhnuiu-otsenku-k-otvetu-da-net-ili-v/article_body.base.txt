# OpenAI запустила API для классификации ответов и упростила платные тарифы

## Как работает Decisions API

API поддерживает три типа ответов:

- вероятности для вариантов «да» и «нет»;
- выбор из заранее заданных категорий;
- оценки по шкале.

В OpenAI приводят такие примеры применения: обнаружение повреждений на фотографиях, автоматическая маршрутизация обращений клиентов и классификация документов. API поддерживает режим без хранения данных и использование, соответствующее требованиям HIPAA, в США и Европе.

Decisions API, вероятно, стал ответом OpenAI на небольшой всплеск интереса к «моделям принятия решений», который Джев запустил в середине сентября.

## Новые уровни API

OpenAI сократила число платных уровней с пяти до трёх: Build, Launch и Grow. Организация автоматически переходит на следующий уровень, когда общая сумма купленных кредитов достигает установленного порога. Месячные лимиты использования составляют $500, $5 000 и $200 000.
