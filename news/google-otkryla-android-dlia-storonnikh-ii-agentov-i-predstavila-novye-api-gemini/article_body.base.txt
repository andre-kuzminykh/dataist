# Google открыла Android Studio для сторонних ИИ-агентов и добавила новые API Gemini

На Android Dev Summit Google представила обновления среды разработки, системных API и оборудования. В центре анонсов — интеграция моделей Anthropic и OpenAI, API для локальных ИИ-агентов на смартфонах и умные очки.

## Android Studio принимает сторонних агентов

В Android Studio Rabbit 2 появится функция Bring Your Own Agent (BYOA). Разработчики смогут использовать открытый протокол Agent Client Protocol (ACP), чтобы запускать прямо в среде разработки более 40 разных агентов для программирования, а не ограничиваться инструментами Google.

Через встроенный магазин можно установить и одновременно запустить Claude Agent от Anthropic, Codex от OpenAI и Google Antigravity. У агентов будет прямой доступ к инструментам среды разработки: структуре проекта, разрешению символов, эмулятору и системе Logcat.

Google также выпустила версию 2.0 рейтинга Android Bench для оценки языковых моделей на сложных задачах. Он проверяет, как модели справляются с проектами разработки, которые длятся несколько дней, учитывая функциональность результата, затраченное время и стоимость.

Изменения в коде, созданные ИИ, бывает трудно проверять. Для этого Google добавляет Change Review: инструмент анализирует ожидающие проверки изменения, составляет отчёты об ошибках и по шагам объясняет внесённые правки. В предварительной версии Android Studio Canary появится и помощник по миграции: он автоматически переводит старые разметки XML в Jetpack Compose. Параллельно Google тестирует Lightbuild — декларативную систему сборки на основе схемы YAML, которую могут читать и редактировать люди и ИИ-агенты.

## Инструменты командной строки сокращают расход токенов

Google расширила Android CLI — инструмент командной строки для разработчиков, которые запускают ИИ-агентов в терминале или в конвейерах непрерывной интеграции. Теперь он доступен как официальный плагин для Claude Code, Codex от OpenAI и Google Antigravity.

Новые команды позволяют агентам создавать в терминале предварительные просмотры интерфейсов Compose. Так можно проверить изменения визуально, не запуская эмулятор. По внутренним тестам Google, с этой функцией агенты выполняли задачи по пользовательскому интерфейсу на 77% быстрее и расходовали до трёх раз меньше токенов. CLI также позволяет подключаться к физическим тестовым устройствам в лабораториях Google, чтобы агенты могли изучать ошибки, связанные с конкретными устройствами.

В инструментах появились новые функции для отладки и анализа производительности. Google встроила библиотеку обнаружения утечек памяти LeakCanary с открытым исходным кодом в Android CLI и Android Studio Profiler. Система анализирует дампы кучи на компьютере, а не на мобильном устройстве, поэтому приложение не замедляется во время тестирования. В A/B-тесте Google с моделью Claude Opus 5.5 от Anthropic инструмент командной строки помог находить и устранять утечки памяти почти вдвое быстрее, сократив расход токенов примерно на 25%.

Другие инструменты командной строки позволяют агентам собирать системные трассировки через Android Performance Analyzer, получать отчёты о сбоях из Firebase Crashlytics и проверять оптимизацию кода с помощью компилятора R8.

Языковые модели часто не обучены на самых новых API, поэтому Google предлагает более 30 Android Skills — наборов документации для агентов. Они помогают проверять правила Google Play перед отправкой приложения, разбираться с безопасностью разрешений и адаптировать интерфейсы для складных устройств и ноутбуков Googlebook.

## Gemini Nano 4 и MCP добавят приложениям функции ИИ-агентов

Помимо инструментов для разработки, Google выпускает API, которые помогут добавлять функции ИИ-агентов в приложения или связывать приложения с системными агентами. Для локальной обработки на устройстве в ML Kit появится альфа-версия Agentic API на базе Gemini Nano 4. Интерфейс автоматически запускает функции, сохраняет историю чата, управляет циклом взаимодействия компонентов и применяет фильтры безопасности.

Google использует протокол Model Context Protocol (MCP) и запускает в бета-версии API AppFunctions — единый слой вызова функций. Через него приложения смогут передавать свои функции локальным агентам или агентам, работающим на уровне всей системы.

На этой основе построен новый альфа-интерфейс Agent-to-UI (A2UI) для Jetpack Compose. Вместо обычных текстовых блоков агенты смогут показывать интерактивные интерфейсы, собранные из компонентов конкретного приложения.

Чтобы подключить сервисы приложений к Google Поиску и приложению Gemini, компания запускает предварительную версию Connected Apps Platform. Разработчики смогут связать приложения через Android MCP или размещённые в облаке MCP-серверы и управлять подключениями из одной консоли. По словам Google, в приложении Gemini уже работают более 50 интеграций партнёров, среди которых Adobe, Peloton и Experian. В ближайшие недели они появятся и в веб-поиске.

## XREAL AURA выводит Android XR в умные очки

Google также рассказала об обновлениях для разных типов устройств. Изменения в Jetpack Compose 1.13 и модели AppState упростят адаптацию приложений для больших экранов. Среда разработки для расширенной реальности (XR) выходит из тестирования: Jetpack XR SDK, XR-эмуляторы в Android Studio и Engine Hub для Unity, Godot и Unreal теперь доступны в стабильных версиях.

Вместе с программными обновлениями Google представила умные очки XREAL AURA, разработанные совместно с производителем устройств XREAL. Глава направления XR Шахрам Изади сообщил, что это первые проводные умные очки на Android XR. Они весят менее 95 граммов и оснащены прозрачными затемняемыми линзами с полем зрения 70 градусов. Вычислительный блок и аккумулятор расположены во внешнем устройстве, которое также работает как тачпад. В нём установлен новый чип Snapdragon Reality Elite от Qualcomm.

Пользователи смогут разместить в поле зрения до пяти приложений Android одновременно или подключить ноутбук по USB-C и вывести его экран на очки. В них также встроен Gemini: он видит и реальное окружение, и виртуальные экраны. ИИ сможет упорядочивать окна, подсказывать по видеоиграм и визуально выделять предметы в комнате.

XREAL AURA уже можно заказать в США, Канаде и Южной Корее за 1099 долларов. Поставки начнутся в середине ноября.
