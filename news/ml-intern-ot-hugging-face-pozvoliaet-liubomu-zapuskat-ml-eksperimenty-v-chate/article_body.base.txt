# Hugging Face запустила ML Intern для экспериментов в чате

## Что делает ML Intern

После запуска система самостоятельно выполняет весь рабочий процесс. Она может:

- создавать наборы данных;
- обучать модели;
- следить за выполняющимися задачами;
- загружать результаты в Hub;
- писать отчёты;
- собирать демки.

Для каждого запуска обучения ML Intern создаёт отдельную панель, где можно отслеживать прогресс.

В показанном Hugging Face примере эксперимент продолжался около шести часов и стоил менее $0.50.

## Сделка с Nvidia

Инструмент снижает порог входа для новых проектов по машинному обучению на платформе. Одновременно сама Hugging Face проходит через приобретение Nvidia. Генеральный директор Nvidia Дженсен Хуанг пообещал сохранить платформу открытой и не привязанной к конкретному оборудованию.
