# Ролики-объяснения для рекламы в дайджесте

Два ролика 16:9 без звука — «ИИ-трансформация» (andre.technology) и «Нейроний» (neuronium.ai), на русском и английском.
Фон — настоящие анимации сайтов, записанные без их текста; поверх — крупные подписи текстами сайтов,
по сцене на шаг. В ролике — только крупные заголовки: мелкий текст (подписи на схемах сайтов, подзаголовки, адреса)
при ширине колонки не читается, поэтому он убран, а со схем при записи стёрт весь текст — остаются фигуры и иконки
(`hide-text.js`). Кнопка — одна, на странице рядом с роликом, в самом ролике её нет.

Результат — в `../assets/`:

| файл | где |
|---|---|
| `*-explainer-{ru,en}.gif` | в письме (почтовые программы не проигрывают видео); у Нейрония свет фона в GIF неподвижный, иначе файл весит 4 МБ |
| `*-explainer-{ru,en}.mp4` | в веб-версии письма: без звука, по кругу, стартует, когда блок появляется на экране |
| `*-explainer-{ru,en}.jpg` | обложка видео, пока оно грузится |
| `ait-vertical-{ru,en}.{mp4,jpg}` | вертикальный (4:5, 720×900) ролик ИИ-трансформации для узкой колонки веб-газеты: сверху — схема сайта крупным планом, снизу — крупный заголовок (`compose-vertical.html`) |

## Как пересобрать

```bash
./make.sh            # всё с нуля, ~10 минут
./make.sh --no-rec   # только поменяли тексты в scenes.py
```

Шаги: `record.js` записывает слайды сайтов → `frames.py` режет запись на сцены →
`scenes.py` задаёт тексты и длительность сцен → `render.js` + `compose.html` (вертикальный — `compose-vertical.html`)
рисуют кадры → ffmpeg / `gifenc.py` кодируют.

Если на сайте поменялась вёрстка и в записи снова виден текст сайта — поправить селекторы в `record.js`
(`NR_TEXT` для neuronium.ai, стиль в ветке `ait-` для andre.technology).
