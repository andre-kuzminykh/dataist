# Meta выпустила приложение для подбора одежды из собственного гардероба

## Как работает Style Sketch

Приложение предлагает сочетания вещей из гардероба пользователя, учитывая его стиль. Образы можно примерить на реалистичной модели, подобранной по фигуре и оттенку кожи.

О запуске первым сообщил консультант по социальным сетям Мэтт Наварра. Meta не ответила на запрос TechCrunch, поэтому планирует ли компания расширить доступность приложения, неизвестно.

## Подбор образов и планы поездок

Style Sketch позволяет выбрать конкретную вещь из гардероба и получить новые идеи образов с её участием. Для поездки приложение может составить план одежды на каждый день: для этого нужно указать место назначения, длительность путешествия и запланированные занятия. Рекомендации учитывают прогноз погоды и маршрут.

Уже есть приложения, которые помогают оцифровывать гардероб и подбирать образы с помощью ИИ. Среди них — приложение стартапа Alta. Такие инструменты есть и в Google Photos: сервис позволяет превратить фотографии одежды в цифровой гардероб и составлять новые сочетания.

У Style Sketch есть доступ к Instagram, где у пользователей уже могут быть фотографии, отражающие их стиль. Эта интеграция может стать для Meta способом выделить приложение среди существующих решений.

## Другие приложения Meta

Style Sketch — одно из нескольких приложений с ИИ, которые Meta выпустила в последние месяцы. Недавно компания представила Waddle World — приложение с ИИ, похожее на тамагочи. Также Meta запустила Pocket — инструмент для создания игр с помощью промтов — и Vibes, приложение для быстрой генерации видео с ИИ.

Новые приложения входят в более широкую программу Meta по их выпуску. Ранее в этом году The Wall Street Journal сообщил, что генеральный директор компании Марк Цукерберг рассказал сотрудникам о планах выпускать значительно больше приложений, чем раньше. По данным издания, ИИ повысил эффективность работы и упростил запуск новых продуктов.
