# Xiaomi вывела открытую модель в лидеры по цене и качеству

## Что показала новая модель

Xiaomi выпустила линейку MiMo-V2.6 из двух моделей. По данным аналитической компании Artificial Analysis, более крупная MiMo-V2.6-Pro набрала 46 баллов в Индексе искусственного интеллекта. Это вывело её на первое место среди доступных открытых моделей — выше Kimi K3 и Qwen.

Стоимость модели составляет $0.435 за миллион входных токенов и $0.87 за миллион выходных токенов.

По расчётам Artificial Analysis, одна тестовая задача обходится примерно в $0.13. Это значительно меньше, чем у моделей с сопоставимыми возможностями, и помещает MiMo-V2.6-Pro на так называемую границу Парето — область, где одновременно учитываются качество и стоимость.

MiMo-V2.6-Pro построена по архитектуре смешения экспертов и содержит 1,02 трлн параметров. При каждом запросе активны только 42 млрд из них. Рядом с ней Xiaomi выпускает меньшую и более экономичную MiMo-V2.6-Flash.

## Ставка на обучение с подкреплением

Xiaomi связывает рост результатов с масштабированным обучением с подкреплением — методом, при котором модель учится через попытки, обратную связь и вознаграждение. Компания расширила этот этап сразу по трём направлениям:

- больше данных на каждый шаг обучения;
- более разнообразные среды для выполнения задач;
- больше вычислительных ресурсов для оценки решений.

Весь процесс, по данным Xiaomi, занял меньше шести дней. Он стоил около $2,62 млн для Pro и $0,85 млн для Flash.

На тесте DeepSWE для задач по программированию результат Pro вырос с 58,4 до 72,6 балла, а Flash — с 48,8 до 65,7.

Чтобы обучение оставалось стабильным при таком масштабе, Xiaomi зафиксировала внутренний механизм распределения модели и добавила несколько уровней защиты от «манипуляций вознаграждением». Так называют приёмы, с помощью которых модель пытается получить высокий балл, не решая задачу по существу.

## Около 7 000 задач с автоматической проверкой

Вместе с моделями Xiaomi выпускает особенно быструю версию Pro-UltraSpeed. Её скорость генерации может быть до 20 раз выше.

Компания также открыла свой набор инструментов для обучения с подкреплением. В него входят:

- технический отчёт;
- полный фреймворк обучения;
- уменьшенная модель для дальнейшего обучения;
- около 7 000 готовых задач с автоматическими проверяющими модулями для разработки программного обеспечения, кибербезопасности, офисной работы и веб-дизайна;
- примерно 1 000 задач для сочинения музыки.

Задания собраны из разных источников. Часть программного кода взята из настоящих запросов на слияние изменений в GitHub, созданных сотрудниками, а также из пользовательских запросов. Другие описания задач сгенерировала языковая модель.

Кибербезопасностные задания основаны на OSS-Fuzz — наборе из десятков тысяч реальных уязвимостей в программном обеспечении. Офисные среды воссозданы синтетически.

## Открытость привлекла внимание Anthropic

Показная открытость Xiaomi заметно отличается от обвинений, которые Anthropic выдвинула двумя неделями ранее. В отчёте своей службы анализа угроз компания изучила случаи злоупотребления Claude, выявленные с декабря 2025 года по август 2026-го, и назвала семь китайских лабораторий, связанных с кампаниями против модели:

- Alibaba;
- Moonshot AI;
- DeepSeek;
- Zhipu;
- Xiaomi;
- MiniMax;
- SenseTime.

По данным Anthropic, суммарно эти лаборатории создали около 190 млн обменов сообщениями, чтобы извлечь возможности Claude для обучения собственных моделей. Anthropic называет такую технику незаконной дистилляцией.

Xiaomi упоминается в отчёте отдельно. В деле GTG-16008 Anthropic отследила более 400 000 обменов за 20 дней в марте и апреле 2026 года. По версии компании, Xiaomi передавала пользовательские диалоги и сеансы программирования из собственных моделей MiMo через OpenClaw и OpenCode в Claude, чтобы расширить набор данных для обучения будущих моделей.

При этом отчёт почти не содержит сведений о происхождении исходных обучающих данных и данных учителя, использованных ранее для внутренней дистилляции моделей-учителей.

Иными словами, Anthropic утверждает, что Xiaomi записывала разговоры пользователей со своими моделями MiMo, а затем отправляла их в Claude для извлечения обучающих данных. Именно эти данные, как следует из обвинения, помогли компании вывести MiMo-V2.6-Pro на первое место среди открытых моделей.
