# Perplexity запустила API для постоянного мониторинга веба

## Поиск по расписанию и отслеживание страниц

Monitor API должен избавить разработчиков от необходимости самостоятельно запускать повторные поиски и писать код для удаления дублей и обнаружения изменений. Perplexity отмечает, что поддерживать такой подход становится почти невозможно, когда нужно следить за сотнями тем и страниц.

Веб-монитор отслеживает поисковый запрос через поиск Perplexity по вебу и новостям. Например, он может находить новости о новых раундах финансирования компаний, работающих над инфраструктурой ИИ. Монитор страниц следит максимум за 10 страницами — например, за страницами с ценами, журналами изменений или правилами. При первом запуске сервис сохраняет исходную версию, а затем возвращает текстовое сравнение, показывающее, что изменилось.

## Как сервис отбирает изменения

Perplexity использует собственную модель принятия решений: она сопоставляет результаты с целью, которую разработчик задаёт на естественном языке. Результаты веб-поиска проверяются на соответствие теме, надёжность источника, новизну и актуальность. Для изменений на страницах оценивается, насколько они важны для заданной цели. Сервис отправляет уведомление с оценкой уверенности, только если результат проходит все пороговые проверки.

Разработчик может отдельно менять порог для каждой проверки и корректировать цель, не создавая монитор заново. Запуски можно настроить с интервалом от 15 минут до недели или задать собственное расписание с помощью cron. Каждый новый запуск продолжает работу с места, на котором остановился предыдущий, а дубликаты отфильтровываются. Webhook-запросы подписываются; после временных ошибок Perplexity автоматически повторяет отправку. Монитор можно приостановить, возобновить или запустить вручную через API либо консоль API.

## Результаты внутренних тестов

Perplexity сравнила Monitor API с сервисами Firecrawl, Exa и Parallel на 60 темах из реальных запросов к Search API. Среди них были новости компаний, технологические новинки и регулирование. Каждый поставщик работал со своим расписанием и настройками, а отдельная модель оценивала релевантность и свежесть результатов.

За первые восемь часов Perplexity получила 63 свежие релевантные страницы. У Firecrawl было 20, у Exa — 15, у Parallel Core и Parallel Lite — по 10. Компания называет результаты предварительными и полученными во внутренних тестах. Те же три конкурента лидировали в августовском бенчмарке Artificial Analysis, где сравнивались традиционные поисковые API для ИИ-агентов; Perplexity в том тесте не участвовала.

## Для каких задач нужен мониторинг

Perplexity приводит в пример отделы продаж, которые отслеживают раунды финансирования и изменения в штате целевых компаний, и аналитиков, следящих за квартальной отчётностью и поглощениями. Другие ИИ-агенты могут сообщать об изменениях цен конкурентов или кратко пересказывать новые правила для специалистов по соблюдению требований.

Веб-мониторы стоят $1 за 1000 успешных запусков, а мониторы страниц — $1 за 1000 загруженных URL. Monitor API уже доступен через API и консоль API. Для него используется тот же ключ, что и для Search API, Context API и Agent API.

## Ставка на инструменты для разработчиков

Perplexity была одной из первых поисковых систем с ИИ, но веб-поиск стал стандартной функцией чат-ботов, включая ChatGPT, Claude и Gemini. В августе The Information сообщило, что Nvidia ведёт переговоры об инвестициях в Perplexity при оценке компании более чем в $30 млрд. Это усиливает для Perplexity необходимость находить прибыльные бизнес-модели.

Компания делает ставку на ИИ-агентов, в том числе Computer и постоянно работающих Teammates, а также на инструменты для разработчиков, такие как Search as Code.

По оценке Dataist, Monitor API переносит регулярный поиск и фильтрацию изменений в готовый сервис, который можно подключить к приложениям и ИИ-агентам. При этом цифры сравнения пока основаны на внутренних тестах Perplexity, а в августовском бенчмарке Artificial Analysis компания не участвовала.
