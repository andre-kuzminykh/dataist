Microsoft меняет роль Copilot в рабочих процессах: новый дизайн объединяет совместную работу в Office, создание приложений и автономных ИИ-агентов, которые продолжают задания после ухода сотрудников. В обновление вошли три раздела — Home, Code и Autopilot. Последний следит за проектами и координирует работу с людьми, а Code создаёт приложения по описанию задачи. Microsoft также запускает управляемый хостинг для таких приложений и расширяет контроль расходов на ИИ. При этом цены на новые возможности пока раскрыты не полностью.
