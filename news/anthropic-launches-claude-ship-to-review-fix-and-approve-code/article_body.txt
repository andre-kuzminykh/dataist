# Anthropic launches Claude Ship to review, fix and approve code

## From review to approval

Claude Ship extends Anthropic’s work on coding tools. The company is now offering not only help writing code but also automation for steps after a pull request, or PR, is created. Coding systems could already review code; Claude Ship’s new feature is an agent that can approve changes according to rules set by the team.

Coding tools are producing larger volumes of code, and reviewing and approving it can slow down releases. Anthropic is proposing that AI agents take on some of this work. The company says many teams are used to having a person approve every change, but that process is harder to maintain when agents are used heavily. According to Anthropic, Claude writes most of the code within the Claude team, and the company wanted to speed up the work that happens after a PR is created.

Claude Ship is launching in beta. Early users can assign it PR reviews, then decide which changes are ready to merge.

## Three tools in the suite

Claude Ship includes Code Review and two new agents:

- <strong>Code Review</strong> — a code review tool already available to all users.
- <strong>PR Steward</strong> — fixes problems including failed CI checks, merge conflicts and Code Review findings. After each change it submits, the agent reports what it fixed and how to revert its changes if needed.
- <strong>Claude Approvals</strong> — applies approval rules that a team records in a repository file. The rules can be written in natural language and can take into account Code Review results and the company’s own classifiers.

Code Review is available to all users, while PR Steward and Claude Approvals are still in beta.

## The team retains control

Because the product is still being tested, Anthropic recommends first enabling approval in observation mode. This lets the team evaluate the system without handing over authority right away. For a cautious rollout, teams can limit its use to one repository and set a monthly spending limit.

Teams also choose where Claude Ship runs, which review mode to use — Quick, Standard or Deep — and which changes to send to a person for a decision. The service is available for GitHub repositories on Claude Team and Enterprise plans.

Dataist’s take: Claude Ship shifts some decisions about code readiness from people to rules set by the team. That makes observation mode, limiting the number of repositories and referring disputed changes to a person important safeguards while PR Steward and Claude Approvals remain in beta.
