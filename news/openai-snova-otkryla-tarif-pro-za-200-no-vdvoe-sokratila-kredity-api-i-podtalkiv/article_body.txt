# OpenAI вернула тариф Pro за $200, но сократила кредиты API

## Переход к оплате по факту использования

Изменение показывает, что OpenAI отходит от подписок, которые компания субсидировала, и движется к оплате по факту использования. В некоторых направлениях так уже работает Microsoft Copilot.

Со временем цены API должны снизиться настолько, чтобы большинству пользователей было выгоднее оплачивать использование по мере необходимости. При этом, как пишет Сотсьо, разница между подпиской и тем, что можно получить через API за потраченный доллар, должна стать небольшой. Это позволит лабораториям ИИ теснее связать выручку с реальной ценностью, которую компании получают от ИИ.
