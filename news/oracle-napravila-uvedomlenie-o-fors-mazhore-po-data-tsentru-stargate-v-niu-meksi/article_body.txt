# Oracle предупредила о форс-мажоре на площадке Stargate

## Что означает уведомление

Форс-мажорные оговорки часто встречаются в договорах в энергетике и сырьевом секторе. Они освобождают сторону от выполнения обязательств, если этому мешают обстоятельства, которые она не может контролировать. В случае с Project Jupiter уведомление не означает выход Oracle из проекта: оно лишь создаёт возможность перенести платежи при срыве запуска в 2028 году.

Уведомление появилось на фоне растущего внимания к строительству дата-центров для ИИ в США и высоких расходов, которые разработчики несут ради создания мощностей для заказчиков вроде OpenAI.

Oracle заявила CNBC, что не ожидает задержки и продолжает выполнять план по Project Jupiter. Компания также сообщила о полной приверженности Нью-Мексико и уверенности в дальнейшей реализации проекта.

Blue Owl Capital, подразделение которой получило уведомление, заявила CNBC, что оно не меняет финансовых обязательств по этому многолетнему проекту.

Oracle и Blue Owl не сразу ответили на запросы TechCrunch о комментариях.

## Проблемы с энергоснабжением

Уведомление последовало за серией неудач на площадке, многие из которых связаны с энергоснабжением. Кампус рассчитан на нагрузку в 2,45 ГВт. Для его работы планируется использовать газовые топливные элементы Bloom Energy, поэтому надёжные поставки газа напрямую влияют на сроки проекта.

[INFO:facts] 2,45 ГВт :: расчётная мощность кампуса | 2028 год :: планируемый запуск | 1 февраля 2027 года :: новая дата поставки газа по трубопроводу | 23 ноября :: крайний срок решения по разрешению на качество воздуха

Газопровод Energy Transfer, по которому газ должен поступать на площадку, задерживается почти на шесть месяцев: новую дату поставки назначили на 1 февраля 2027 года. Регуляторы неоднократно отказывали в разрешениях на строительство этой линии. В августе Bloomberg сообщил, что после этих отказов маршрут газопровода изменили.

Отдельное разрешение на качество воздуха для топливных элементов, которые должны снабжать кампус энергией, пока не выдано. Департамент окружающей среды штата должен принять решение до 23 ноября.

## Проект Stargate в Нью-Мексико

Project Jupiter — одна из ключевых площадок Stargate, инфраструктурной инициативы в сфере ИИ, о которой Oracle, OpenAI и SoftBank объявили вместе с президентом Дональдом Трампом в начале его второго срока.

Кампус встретил сопротивление местных жителей и экологических организаций. Перед промежуточными выборами он стал предметом политических споров. По данным Bloomberg, Oracle проводит в штате кампанию по работе с общественностью, чтобы заручиться поддержкой критиков проекта.
