# После сбоя Microsoft объявила режим повышенной готовности и подключит ИИ-агентов

## Что происходило во время сбоя

Сбой в Exchange Online стал частью серии крупных перебоев в технологических сервисах. Президент подразделения M365 Core Джейсон Хендерсон сообщил сотрудникам, что это был самый масштабный по числу затронутых клиентов инцидент в истории Exchange Online: такого количества пользователей ещё не оставались без почты на столь долгое время.

Вице-президент Microsoft Аманда Сильвер, курирующая M365 Core и корпоративную платформу ИИ-агентов Work IQ, сравнила обстановку для инженеров с «туманом войны». По её словам, сотрудники обменялись более чем 11 000 сообщениями в 11 чатах Teams, пытаясь разобраться в случившемся. Нужные для диагностики данные оказались распределены по разным внутренним системам отслеживания.

Исполнительный вице-президент Microsoft по Copilot, агентам и платформе Чарльз Ламанна назвал масштаб возникших проблем примерно десятилетним объёмом сбоев, которые можно считать допустимыми.

## Зачем Microsoft нужны ИИ-агенты

Code Red — режим высшего приоритета, который мобилизует сотрудников для устранения критических инцидентов. Microsoft объявила его, чтобы изменить подход к предотвращению крупных сбоев и реагированию на них. Цель компании — в будущем устранять глобальные инциденты в течение часа.

Для ускорения диагностики Microsoft намерена привлекать больше ИИ-агентов: они должны помогать инженерам находить причину неполадок и быстрее разбирать данные. При этом у применения таких систем в корпоративной инфраструктуре остаются риски: у Meta и Amazon уже происходили серьёзные инциденты из-за сбоев ИИ-агентов или их неосторожного использования.

## Сокращения и автоматизация

За последний год Microsoft уволила или вынудила уйти тысячи сотрудников. Компания также предложила выкупить контракты у ещё 60 000 работников — это более четверти оставшегося персонала.

По оценке Dataist, план Microsoft связывает ускорение реакции на сбои с автоматизацией диагностики, тогда как сама компания продолжает сокращать штат. Насколько ИИ-агенты смогут компенсировать потерю сотрудников, пока неясно.
