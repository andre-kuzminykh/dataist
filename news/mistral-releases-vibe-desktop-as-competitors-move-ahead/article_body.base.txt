Mistral has released a desktop app for its AI agent Vibe, previously known as Le Chat. It lets users run several tasks at once and watch them progress. The app combines Vibe CLI’s local capabilities with Vibe Code Web’s cloud sessions: the agent can work with a local repository or in a cloud sandbox, while Git worktrees keep parallel tasks in the same project separate. Vibe Desktop is available for macOS and Windows; a Linux version is planned for later.

# Mistral releases Vibe Desktop, but competitors are ahead in computer control

## What the desktop version can do

Vibe was previously available as a web app, a command-line tool and a smartphone app. Now, in Work mode, the agent can also access local files. Mistral has not said that Vibe can control a computer — for example, by opening apps or working in a browser.

## Competitors have gone further

Since spring, Anthropic’s desktop app has let Claude open apps, control browsers and fill in spreadsheets. Mistral narrowed the gap at the model level in October with the release of Large 4, but in direct comparisons the model still falls well behind Gemini 4 Carbon and Claude Opus 5.5, and trails China’s strongest open models as well.

The French company gets most of its revenue from businesses and government organizations. They use its models through APIs or deploy them on their own infrastructure.

Dataist’s take: Vibe Desktop expands the ways users can work with the agent, but for now it does not offer the computer-control capabilities already available in Anthropic’s app. This is especially notable given Large 4’s lag in comparisons with leading models.
