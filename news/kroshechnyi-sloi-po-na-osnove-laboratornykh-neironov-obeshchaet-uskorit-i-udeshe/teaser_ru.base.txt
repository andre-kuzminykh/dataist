Сан-францисская The Biological Computing Co. (TBC) вместе с Amazon Web Services готовит к запуску модель генерации видео по тексту, которую называет первой «полученной из нейронов». Она основана на открытой видеомодели и, по заявлению компании, должна создавать ролики в пять раз быстрее, а стоимость инференса снизить на 80% по сравнению с исходной моделью — при более высоком качестве. Биологические нейроны при этом не участвуют в работе системы: их активность использовали для создания небольшого программного адаптера. Модель планируют запускать на чипах AWS Trainium, предоставлять через Amazon SageMaker AI и продавать в AWS Marketplace, но пока доступна только форма заявки на ранний доступ.
