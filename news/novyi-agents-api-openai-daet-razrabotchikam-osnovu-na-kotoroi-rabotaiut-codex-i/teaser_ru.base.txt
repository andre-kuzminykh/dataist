OpenAI выпустила публичную бета-версию Agents API — инструмента для создания облачных ИИ-агентов, которые могут работать часами, выполнять код и обрабатывать файлы. API использует ту же инфраструктуру, что лежит в основе Codex и ChatGPT. Среди его возможностей — автоматическое управление контекстом, параллельный вызов инструментов и передача задач субагентам.
