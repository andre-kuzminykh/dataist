# OpenAI открыла Agents API для долгоживущих ИИ-агентов

Разработчики могут выбирать между песочницами, размещёнными OpenAI, и решениями партнёров — Cloudflare, Vercel и Oracle. Дополнительной платы за инфраструктуру нет: стоимость зависит только от количества использованных токенов. API создан на базе открытого кодового каркаса Codex и поддерживает MCP, пользовательские функции и встроенные инструменты, включая веб-поиск.
