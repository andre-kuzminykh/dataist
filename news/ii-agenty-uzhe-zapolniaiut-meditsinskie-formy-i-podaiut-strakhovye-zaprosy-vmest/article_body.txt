# ИИ-агенты OpenAI берут на себя медицинские формы и страховые запросы

## Как агенты работают с медицинскими системами

OpenAI нацелилась на проблему, с которой сталкиваются медицинские организации: у многих систем здравоохранения нет API для обмена данными. Встроенные в Agents API в конце сентября агенты управления компьютером работают через существующие интерфейсы — переносят сведения из электронных медицинских карт во внешние веб-порталы и обратно.

Например, если пациент сообщает о боли в спине, агент должен найти подходящие записи о предыдущих обследованиях, подготовить направление на МРТ и ответ пациенту, а также заполнить на портале страховщика запрос на предварительное согласование процедуры. Перед отправкой черновики проверяют врачи и ответственные административные сотрудники. Функции доступны через API, а также в ChatGPT for Healthcare и ChatGPT for Clinicians.

## Результаты тестирования и стоимость

В описанной OpenAI оценке GPT-6 Astra выполняла задачи из входящих разделов электронных медицинских карт. Среди примеров — подготовка дозировки ибупрофена для ребёнка со сломанной рукой. Врачи проверили 325 заданий: 99% подготовленных материалов они признали клинически безопасными. В 93% из 646 оценок подготовка оказалась очень или чрезвычайно полезной.

Для административных процессов — запросов на предварительное согласование, апелляций и заказов медицинского оборудования — OpenAI приводит результаты независимого бенчмарка HealthAdminBench, разработанного исследователями Стэнфордского университета. GPT-6 Astra набрала 94,3% возможных баллов, а GPT-6 Luna, рассчитанная на низкую стоимость API, — 91,8%. По данным OpenAI, одна задача с GPT-6 Luna обходится примерно в 8,5 цента — на 98% дешевле, чем с Astra. Обе модели проходили бенчмарк с максимальным уровнем усилий для рассуждения.

[INFO:facts] 99% :: клинически безопасных задач | 94,3% :: результат GPT-6 Astra | 91,8% :: результат GPT-6 Luna | 8,5 цента :: стоимость задачи с GPT-6 Luna

## Где уже используют агентов

Несколько организаций участвуют в развитии технологии. В CVS Health агенты обрабатывают направления и консультации узких специалистов, проходя через разные системы. По сообщению OpenAI, один агент за выходные разобрал накопившиеся за несколько месяцев исходящие документы, а другой ежедневно выполняет системные операции для десятков тысяч консультаций. CVS Health опубликовала архитектуру своего программного обеспечения под названием Agent Kit на GitHub.

В страховой компании Cigna Healthcare модели объединяют сведения о пациентах из более чем 10 систем. Abridge разрабатывает агентов для планирования выписки пациентов. Компания Ambience показала дополнительные меры безопасности: если в медицинской карте не хватает ясности, агент останавливается и запрашивает мнение врача. Стартапы вроде Assort используют эту функцию в Codex, чтобы оформлять направления в программах управления практикой, чьи API не позволяют выполнить последний шаг.

## Данные пациентов и требования к конфиденциальности

Поскольку агенты напрямую работают с электронными медицинскими картами, защита чувствительных данных становится одним из основных вопросов. OpenAI заявляет, что не использует данные организаций для обучения базовых моделей. По словам компании, ChatGPT for Healthcare поддерживает разграничение доступа по ролям и журналы аудита. Организации также могут настроить приложения и рабочие среды так, чтобы агент получал доступ только к необходимым для конкретной задачи записям и действиям.

Для процессов, подпадающих под требования HIPAA и связанных с защищённой медицинской информацией, организациям нужно подписать с OpenAI соглашение Business Associate Agreement (BAA). Кроме того, необходимо использовать сервисы, охваченные соглашением, и задать требуемые параметры безопасности и хранения данных. За правильное применение системы отвечают сами медицинские организации, но у OpenAI как стороны соглашения тоже есть обязательства по HIPAA. Медицинские специалисты из США, прошедшие проверку и использующие бесплатный индивидуальный план ChatGPT for Clinicians, также могут подписать BAA. Соглашение распространяется только на охваченные им функции.

В проекте CVS Health данные остаются в инфраструктуре, контролируемой компанией. По словам OpenAI, CVS проверяет действия агентов по снимкам экрана и журналам операций. При этом в сообщении не уточняется, где обрабатываются снимки и как долго они хранятся. Требования Общего регламента ЕС по защите данных (GDPR) также не рассматриваются: пока предложение ориентировано на США.

По оценке Dataist, агенты могут снять часть административной нагрузки в раздробленной системе здравоохранения, но приведённые показатели точности и стоимости сами по себе не определяют перспективы технологии. Многое зависит от надёжности работы с существующими системами, возможности контролировать действия агентов и того, останется ли решение клинически или юридически значимых вопросов за человеком.
