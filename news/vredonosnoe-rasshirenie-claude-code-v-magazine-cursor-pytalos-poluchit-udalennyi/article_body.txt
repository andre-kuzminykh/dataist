# В магазине Cursor обнаружили вредоносную версию расширения Claude Code

Расширение пыталось получить имя устройства и пользователя, сведения об операционной системе и публичный IP-адрес. Оно также пыталось настроить удалённый доступ для злоумышленника. По словам Cursor, на большинстве компьютеров это, вероятно, не сработало бы: для такого доступа нужны права администратора.

После обнаружения вредоносного расширения Cursor удалила его и отключила весь магазин. Компания вместе с поставщиками услуг нейтрализовала вредоносную программу и проверила, что дальнейшего риска нет, после чего магазин снова заработал. Cursor заявила, что другие расширения не пострадали.
