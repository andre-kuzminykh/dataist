Microsoft is rebuilding Copilot around autonomous work and variable costs. The company is introducing Autopilot, an agent that can keep running in the cloud after a user leaves, while moving Autopilot, Code and Cowork from fixed pricing to usage-based billing. It is also splitting Copilot into Home, Code and Autopilot, a structure that makes the product look less like one assistant and more like a metered operating layer for work.
