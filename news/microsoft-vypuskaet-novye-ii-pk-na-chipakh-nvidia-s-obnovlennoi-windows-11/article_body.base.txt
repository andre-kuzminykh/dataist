# Microsoft выпустила ноутбук Surface с чипом Nvidia за $2 600

## Ноутбук и рабочая станция

Surface Laptop Ultra выйдет в двух базовых версиях: начальная модель стоит $2 600, а вариант с более мощным чипом — от $3 700. Дополнительная память и хранилище поднимают цену до $5 900. По словам Microsoft, самая дорогая конфигурация уже распродана.

Рабочая станция Surface RTX Spark Dev Box на базе чипа RTX Spark стоит от $6 000. На неё предустановлены инструменты Microsoft для разработчиков: VS Code, GitHub Copilot CLI, WSL и PowerShell 7.

Оба компьютера предназначены для локального и бесплатного запуска ИИ-моделей. Для этого в них предусмотрены подходящие процессоры, графические процессоры, объединённая память и другие аппаратные изменения, включая улучшенное охлаждение.

Устройства работают на обновлённой версии Windows 11 с функцией «Контейнеры выполнения». По заявлению Microsoft, она упрощает изоляцию ИИ-агентов. На мероприятии генеральный директор компании Сатья Наделла уточнил, что функция появится у всех пользователей Windows 11.

Наделла объяснил, что за последние три-четыре года в Microsoft поняли: одной модели недостаточно. Для работы нужны оркестрация и память за пределами модели, а также слой, который объединяет несколько моделей, контекст, память и пространство возможных действий.

Он добавил, что Microsoft предоставляет такую возможность не только для собственных приложений, но и для приложений, работающих с агентами других разработчиков. По его словам, именно так компания видит дальнейшее развитие платформы Windows.

## Для разработчиков и творчества

Новые устройства явно ориентированы на разработчиков. Microsoft предлагает скидку до $1 000 тем, кто сдаст MacBook Pro. Компьютеры Mac стали популярны среди разработчиков и поклонников ИИ-агентов, особенно в Кремниевой долине.

При этом, по словам Microsoft, мощная графика позволяет использовать Surface для создания контента, обработки видео и игр.

В среду характеристики нового ПК на Windows с чипом Nvidia RTX Spark представила и Dell. Компания сообщила подробности о Dell XPS 16 Creator Edition. Его уже можно предзаказать в Best Buy: поставки ожидаются в конце октября, цена — $3 800.
