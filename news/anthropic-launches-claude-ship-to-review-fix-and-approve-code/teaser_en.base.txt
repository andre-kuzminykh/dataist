Anthropic has introduced Claude Ship, a set of AI agents that helps review code changes, fix problems and automatically approve routine updates according to a development team’s rules. The service is launching in beta for Claude Team and Enterprise plans and works with GitHub repositories. The suite includes the already available Code Review and two new beta agents, PR Steward and Claude Approvals. Teams can delegate some reviews and merge decisions to AI while retaining control over the settings and cases that should be escalated to a person.
