Nvidia’s SoL-Pi cuts coding-agent token use by optimizing the control layer, not the model. The system searches for changes to the pipeline that connects an agent to its working environment, then tests them against tasks kept out of the search process. On EdgeBench, its most economical configuration used 49% fewer tokens than Pi while retaining 93.7% of Pi’s score. That makes the result less a claim about smarter models than a case for treating the agent’s operating logic as a major cost lever.
