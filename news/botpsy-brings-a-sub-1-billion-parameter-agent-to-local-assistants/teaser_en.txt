BotPsy is an on-device personal assistant powered by an agentic language model with fewer than 1 billion parameters. Tether AI Research introduced BotPsy, a 0.8-billion-parameter model for calling tools and completing tasks as a personal assistant. Built on Qwen3.5-0.8B, it is designed to run directly on a device, keeping user data local and reducing reliance on cloud models. In tests, BotPsy outperformed evaluated models with up to 1.2 billion parameters across six benchmarks for tool use and AI agents. It is suited to low- and medium-complexity tasks, but can make mistakes and is not intended for high-stakes decisions.
