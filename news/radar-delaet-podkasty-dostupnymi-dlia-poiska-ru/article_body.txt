# Radar делает подкасты доступными для поиска и ИИ-агентов

Particle, стартап бывших инженеров Twitter, запустил Radar — поисковик подкастов, который расшифровывает аудио и понимает содержание разговоров. Сервис уже индексирует более 130 000 подкастов, включая все 200 самых популярных шоу Apple в 135 категориях, и ежедневно добавляет 20 000 эпизодов. Radar извлекает цитаты, отмечает людей, компании и темы, отслеживает их упоминания и предоставляет данные через веб-интерфейс, API и MCP. Основными клиентами стали хедж-фонды, которым нужны сведения, недоступные обычным ИИ-агентам, ориентированным в основном на текст.

## Поиск по разговорам

Particle основала Сара Бейкпур, ранее работавшая в Twitter. Теперь компания меняет направление: вместо приложения для чтения новостей она развивает технологию индексации устных разговоров из подкастов.

По словам Бейкпур, наибольший объём запросов к API сейчас дают хедж-фонды, которые напрямую подключают сервис к своим системам. Инструменты Radar также могут пригодиться журналистам и исследователям. Среди других хорошо платящих клиентов — поисковые платформы на базе ИИ и перепродавцы данных. В число партнёров Radar входит Exa — поставщик поискового API для ИИ-агентов.

Идея выросла из одной из самых востребованных функций приложения Particle. Через API оно находило интересные фрагменты подкастов и добавляло их к связанным новостям в ленте.

Команда Particle увидела ценность этой технологии, но поняла, что внутри новостного приложения она используется ограниченно. На фоне роста интереса к ИИ-агентам компания решила сосредоточиться на API для анализа подкастов.

Бейкпур описывает замысел как создание API для анализа новых медиа и аудио. Большинство сервисов и агентов с API сканируют веб-страницы и работают с текстом, тогда как Radar добавляет к этим данным аудио. Обычно ИИ-агенты не видят содержимое аудиозаписей, пока их кто-то не расшифрует.

## Что умеет Radar

Radar расшифровывает более 130 000 подкастов — компания называет его крупнейшим сервисом расшифровки подкастов. В индекс входят все 200 самых популярных подкастов Apple в 135 категориях, а каждый день туда добавляются 20 000 новых эпизодов.

В расшифровках указаны говорящие и подробные метаданные. Radar распознаёт обсуждаемые сущности: людей, компании, бренды, продукты и темы.

Сервис отслеживает упоминания этих сущностей в разных подкастах и отправляет уведомления. Их можно получать сразу после упоминания или в виде ежедневной либо еженедельной подборки.

Уведомления приходят по электронной почте, в Slack или через вебхук. Для них доступны фильтры: например, можно получать сообщения только тогда, когда определённый гость обсуждает заданную тему. Поиск также можно ограничить популярными подкастами.

Radar выделяет самостоятельные фрагменты с временными метками. Пользователь может одновременно прослушать их и прочитать соответствующую часть расшифровки.

Бейкпур объясняет, что команда заранее отбирает заметные фрагменты. Это позволяет быстро понять, что обсуждали в выпуске, если у пользователя нет времени слушать весь подкаст и он не хочет читать краткое содержание.

Radar также отслеживает темы выпуска, упомянутых людей и объекты, время их появления, оценки и отзывы слушателей, рекламу и другие сведения. Отдельный поисковик рекламы в подкастах находит все эпизоды, где рекламировалась конкретная компания, и показывает, как часто такие размещения появлялись со временем.

Дополнительные возможности могут быть связаны с анализом политического уклона, рейтингами подкастов, оценкой аудитории, спонсорскими размещениями и соответствием контента бренду.

## API для ИИ-агентов

Все эти функции доступны через веб-интерфейс Radar, но главным продуктом компания считает API и MCP. Они позволяют ИИ-агентам и другим компаниям программно получать те же данные и возможности анализа.

Стоимость Radar начинается с $29 в месяц за одного пользователя. Тариф для компаний стоит $399 в месяц и включает 20 пользователей. Стоимость доступа к API рассчитывается индивидуально.

В будущем Particle планирует добавить в индекс другие источники аудио и видео, включая YouTube, а также короткие фрагменты новостей. Компания рассчитывает, что это поможет ИИ-агентам работать не только с текстом веб-страниц, но и с содержанием разговоров, интервью и видеоматериалов.
