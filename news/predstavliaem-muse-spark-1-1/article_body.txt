# Meta представила Muse Spark 1.1 для ИИ-агентов

Meta Superintelligence Labs представила Muse Spark 1.1 — мультимодальную модель с рассуждением для задач ИИ-агентов. По сравнению с первой Muse Spark она заметно улучшила работу с инструментами и компьютером, программирование и мультимодальное понимание, а также получила контекстное окно на 1 млн токенов. Модель уже доступна в режиме рассуждения в приложении Meta ИИ и на meta.ai, а разработчики могут протестировать её через публичную версию нового Meta Model API.

## Muse Spark 1.1 и ИИ-агенты

Muse Spark 1.1 рассчитана на персональные задачи ИИ-агентов, где нужно планировать действия и координировать работу с разными внешними приложениями и сервисами. Модель умеет без предварительного обучения переносить навыки на новые встроенные инструменты, MCP-серверы и пользовательские навыки.

Сложные проекты она выполняет быстрее первой Muse Spark: модель обучали координировать мультиагентные системы и сокращать общую задержку выполнения. В роли главного агента Muse Spark 1.1 собирает контекст, составляет план и распределяет работу между параллельными подагентами. В роли подагента она придерживается своей задачи, понимает доступные инструменты и знает, когда нужно передать управление главному агенту.

Модель может самостоятельно управлять контекстным окном размером до 1 млн токенов. Она сохраняет выполненные действия, извлекает сведения из значительно более ранних этапов работы и сжимает контекст так, чтобы в нём оставались критически важные шаги.

[INFO:facts] 1 млн :: токенов в контекстном окне

Muse Spark 1.1 умеет выполнять сценарии работы с компьютером сразу в нескольких приложениях, даже когда информация в них меняется по ходу задачи. Она сохраняет контекст в длинных сеансах, подстраивается под новые требования и взаимодействует с незнакомыми интерфейсами при минимальном участии человека.

Модель не пытается выполнять каждый шаг на рабочем столе, нажимая на каждую кнопку по очереди. Она определяет, когда быстрее написать программу, а когда проще воспользоваться интерфейсом напрямую, и может создавать группы действий для каждого этапа. Её обучали писать программы, выбирать прямое взаимодействие и формировать пакеты операций.

В сценарии с организацией званого ужина новый контекст появляется уже во время выполнения задачи и меняет исходные требования. Muse Spark 1.1 замечает изменения при оформлении заказа на ужин и самостоятельно вносит необходимые обновления.

## Программирование

На реальных задачах с большими и сложными кодовыми базами Muse Spark 1.1 заметно улучшила результаты. Модель может находить и исправлять сложные ошибки, добавлять функции в корпоративные системы и выполнять масштабные миграции кода. В сценариях создания веб-приложений и сквозного ответа на вопросы она также существенно опережает первую модель.

Muse Spark 1.1 обучали плавно адаптироваться к разным средам запуска и надёжно работать со сложными многошаговыми сценариями. Она поддерживает популярные настройки агентов для программирования, включая режим планирования, привязку к цели, делегирование задач подагентам и сжатие контекста.

В демонстрации с OpenCode модель создаёт веб-приложение с чатом, автоматически делает снимки экрана, находит по ним ошибки, заметные пользователю, связывает проблемы с соответствующими участками кода, исправляет их и проверяет результат. В этом процессе она объединяет программирование, мультимодальное понимание и вызов инструментов.

Разработчики и исследователи Meta ежедневно используют Muse Spark 1.1, чтобы быстрее создавать проекты и выполнять рабочие задачи. На основном внутреннем тесте Meta Internal Coding Bench модель заметно улучшила результат по сравнению с Muse Spark и конкурирует с ведущими альтернативами.

Исследователи также начали автоматизировать задачи разработки и оценки моделей, используя Muse Spark 1.1 в своих рабочих процессах.

В другой демонстрации, посвящённой оценке DeepSWE в OpenCode, Muse Spark 1.1 проверяет себя на части задач DeepSWE при разных уровнях силы рассуждения и создаёт по результатам аналитическую панель.

## Мультимодальные задачи

Помимо программирования и возможностей ИИ-агента, Muse Spark 1.1 хорошо справляется с восприятием, мультимодальным рассуждением и использованием инструментов. Модель может взаимодействовать с реальными средами и создавать результаты, связанные с исходными данными. Среди её возможностей — генерация визуальных артефактов по коду, подробное описание изображений и видео, а также выполнение рабочих процессов ИИ-агента в мультимодальных сценариях.

Мультимодальные способности особенно полезны в задачах, где восприятие и действие должны происходить одновременно. Muse Spark 1.1 анализирует визуальные и аудиоданные, сохраняет детали на протяжении длинного рабочего процесса и использует их, управляя компьютером от имени пользователя.

В сценарии с агентом для Facebook Marketplace модель получает видео, снятое на смартфон, выбирает из него подходящие фотографии, анализирует товар, открывает браузер пользователя и самостоятельно создаёт объявление на Facebook Marketplace.

## Проверка безопасности

Перед выпуском Meta провела масштабную проверку безопасности в соответствии с передовой системой масштабирования ИИ. Эта система определяет набор оценок, модели угроз и пороги для выпуска наиболее передовых моделей компании.

Проверки по всем категориям рисков — химическим и биологическим угрозам, кибербезопасности и потере контроля — показали, что Muse Spark 1.1 работает в безопасных пределах. Модель устойчива к прямым попыткам обхода ограничений и косвенным атакам через ненадёжные данные, внедрение запросов и атаки с использованием запроса разработчика. В результате у неё выше устойчивость к состязательным атакам, ниже частота галлюцинаций и слабее склонность соглашаться с пользователем во вред точности ответа.

Полное описание мер безопасности для версии 1.1 опубликовано в отчёте об оценке Muse Spark 1.1.

## Meta Model API

Разработчики впервые получили возможность создавать проекты на базе Muse Spark 1.1 через новый Meta Model API, который сейчас работает в режиме публичного предварительного доступа.

Ранние партнёры Meta называют модель полноценной основой для ИИ-агентов: она сочетает работу с длинным контекстом, программирование и рассуждение для масштабных задач ИИ-агентов.

По словам партнёров, Muse Spark объединяет контекст на миллион токенов, поддержку изображений, видео и PDF, встроенный поиск с цитатами, рассуждение, программирование, структурированный вывод и параллельный вызов инструментов в пакете, совместимом с OpenAI.

В Cline отметили, что модель подходит для серьёзных задач по программированию с ИИ-агентами благодаря работе с инструментами и цене, позволяющей запускать такие нагрузки в большом масштабе.

Yashodha Bhavnani, вице-президент по продуктам ИИ в Box, сообщила, что на корпоративном наборе задач Box Muse Spark показала возможности, сопоставимые с ведущими передовыми моделями. По её словам, модель также хорошо подходит для структурированных процедурных процессов в профессиональных услугах, государственном секторе и промышленности.

В OpenClaw Muse Spark 1.1 назвали быстрой и мощной моделью для запуска ИИ-агентов.

Meta сообщила, что продолжает обучать ещё более способные модели и планирует рассказать о них позже.
