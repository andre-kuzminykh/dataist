Anthropic has released Claude Opus 5.5, a model it says beats Fable 5.1 and its previous flagship Mythos 5.1 on several agent benchmarks. The more consequential part of the launch is the price: Opus 5.5 costs $4 per million input tokens and $20 per million output tokens, 20% less than Opus 5 and 60% less than Fable 5.1’s base API rates. OpenAI released GPT-6 Sol and GPT-6 Luna on the same day, turning the launch into a test of how much useful autonomous work companies can buy for a dollar.
