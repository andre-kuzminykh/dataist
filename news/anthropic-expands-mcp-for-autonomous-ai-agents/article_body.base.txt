Anthropic said its developer tools for the MCP protocol are downloaded more than 700 million times a month, and more than 10,000 MCP connections are available for Claude. Two years after the protocol launched, the company is expanding it with features for long-running background tasks, requesting information from users, and transferring files. The new capabilities are intended to help AI agents interact with one another and coordinate workflows more effectively.

## Anthropic expands MCP for autonomous AI agents

## Tasks and clarifications without constant supervision

Tasks and Elicitation became generally available after open testing in October. Tasks lets a server carry out long-running work in the background and report the result when it is ready. With Elicitation, an ongoing process can pause and ask the user for specific missing information. Both features give MCP servers greater autonomy.

## Skills and file transfers

Skills over MCP is in open beta. The feature lets developers connect server tools to skills that help Claude complete long, multi-step tasks. According to Anthropic, skills include best practices, step-by-step workflows, and instructions tailored to a user’s or organization’s account.

Anthropic is also preparing file upload support. Once launched, Claude will be able to send PDFs, spreadsheets, and images directly to MCP servers. The company plans to add the capability to Claude and Claude Code soon for Pro, Max, and Ultra subscribers, as well as eligible Team and Enterprise customers.

## The technical foundations for scaling MCP

The new features build on technical changes Anthropic has made over the past year. Tool Search reduces memory use during active conversations by loading descriptions of individual tools only when needed. According to the company, in configurations with multiple servers, this can reduce context-window usage by more than 85%.

The current MCP specification does not require session data to be stored persistently and works across all Claude products. Anthropic aims to make server development easier and improve reliability as workloads grow.

For enterprise customers, the company released Enterprise Managed Auth. Administrators can approve supported servers once, after which employees connect to them automatically. MCP Apps lets developers embed full interfaces in Claude, alongside an active chat or in full-screen mode.

## How the protocol developed

In November 2024, Anthropic introduced the Model Context Protocol, an open standard that gives AI assistants a unified way to access workplace tools, development environments, and other data sources. In March 2025, OpenAI CEO Sam Altman announced that the company would use its competitor’s standard in its products. In May 2025, OpenAI updated its Responses API to support remote MCP servers. In January 2026, researchers at the Shanghai Artificial Intelligence Laboratory introduced the Science Context Protocol (SCP), modeled on MCP.

Dataist’s take: Anthropic is developing MCP in two directions at once: making it easier to connect to tools and adding mechanisms for agents to work for extended periods without constant user involvement. But some of the new capabilities are not yet available to everyone: Skills over MCP remains in open beta, and the company has only said it plans to launch file support.
