В четверг вредоносная версия расширения Claude Code около 11 часов была доступна в магазине расширений Cursor для VS Code. По данным компании, установить её могли до 5 000 пользователей. Расширение пыталось собирать данные об устройстве и настраивать удалённый доступ для злоумышленника. Cursor удалила расширение и временно отключила весь магазин, а после устранения угрозы восстановила его работу. Другие расширения не пострадали. Anthropic к разработке вредоносной версии отношения не имела.
