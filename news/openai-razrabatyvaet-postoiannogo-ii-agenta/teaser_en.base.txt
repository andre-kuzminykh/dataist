OpenAI is testing a new “persistent mode” feature for its main AI agent Codex. In this mode, the agent is supposed to continue working until the user stops it, and after completing a request, independently create new tasks and return to them in subsequent sessions. The feature was found in the code of the command-line version of Codex; so far, it has not been announced or widely rolled out. OpenAI confirmed the testing but said it does not plan to release “persistent mode” in the near future. The mode may also gain access to interaction history and send messages to the user without a separate request.
