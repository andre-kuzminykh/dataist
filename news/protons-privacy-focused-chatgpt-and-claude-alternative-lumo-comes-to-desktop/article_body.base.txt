# Proton releases desktop version of its Lumo AI app

The company is developing services intended to replace Google and Microsoft products, from email and cloud storage to productivity apps and password management. Now it has added a desktop version of its Lumo AI app. The launch reflects a shift in consumer AI services from answering questions to agents that carry out tasks for users.

## Access to files and services

Desktop apps from OpenAI, Anthropic, Meta and other developers also let people use AI on their computers. But these programs’ access to personal data raises concerns. This week, Apple said it would strengthen security settings for apps that request full disk access, including AI apps.

Lumo Desktop connects to local tools and third-party services. Available connections include the file system, shell command execution and browser content retrieval, Proton Mail, as well as Confluence, Dropbox and Jira. The app supports local and remote MCP servers, a protocol that lets AI agents access external data sources.

Users can set permissions separately for each connection: allow Lumo to act automatically, require confirmation or prohibit actions entirely. Individual tools can also be turned off in the Tools menu directly in a conversation. The same settings are available for scheduled tasks: users can specify what the AI is allowed to do on its own and when it must ask for permission.

## Privacy and skills

Proton says that conversations and information from connected apps and files are not used for personalized advertising or model training. The company also says chat history is encrypted so that only the user can read it, and that it keeps no server logs. According to Proton, the limited amount of data it retains is protected by Swiss privacy law.

The data is hosted on European infrastructure that, the company says, falls outside the scope of the US CLOUD Act, which governs how law enforcement agencies access data held by cloud services. Proton also said its first Nvidia B300 cluster, built to Open Compute Project (OCP) standards, has begun operating in Switzerland.

The desktop version includes Skills, a feature for saving instructions, templates and reference files to reuse across different conversations with Lumo. The previous Custom Lumos feature will be moved to the Skills format.
