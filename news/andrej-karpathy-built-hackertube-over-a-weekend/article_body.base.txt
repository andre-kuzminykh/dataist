## What Claude Code did

Karpathy assigned Claude Code almost all the work, from analyzing data to configuring the server. He had to handle a few tasks manually: get a Google Cloud API key, rent a server, and buy a domain.

According to Karpathy, projects that once took weeks can now be completed in a few hours. For HackerTube, Claude processed two decades of Hacker News comments and identified 6,454 videos; TristanTube was built from Tristan Hume’s list of channels.

HackerTube requires no registration. Instead of thumbnails designed to attract attention, the service shows a random frame from the middle of each video; viewing progress is stored locally in the browser. Karpathy believes this makes for a more convenient viewing experience than YouTube recommendations.

Dataist’s take: HackerTube shows how an AI agent can take on a substantial share of the work involved in building a small service, from processing data to configuring a server. But Karpathy still had to take some steps himself: he got an API key, rented a server, and bought a domain.
