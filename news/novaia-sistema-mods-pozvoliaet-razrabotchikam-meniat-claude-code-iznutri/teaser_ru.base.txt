Anthropic выпустила Mods — систему плагинов для Claude Code, которая позволяет разработчикам менять внешний вид и работу инструмента. Моды написаны на JavaScript или TypeScript и подключаются к событиям: вызовам инструментов, запросам пользователя и отрисовке интерфейса. С их помощью можно добавить панели рядом с чатом, перехватывать вызовы инструментов и создавать новые команды. По словам компании, даже некоторые встроенные функции, например команда /diff, уже сделаны как моды.
