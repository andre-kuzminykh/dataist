# AI-перевод романа — вертикальные карточки · Спецификация

7 **вертикальных** карточек **1080×1350** (4:5, Instagram) — инверсия стиля урока
Loop Engineering: **тёмный фон `#050505`, белый текст**, палитра строго
**оранжевый `#F97316` + фиолетовый `#8854F3`**, шрифт **JetBrains Mono**,
иконки inline-SVG, логотип AIT слева вверху, счётчик `NN / 07` справа.

Большие цифры — градиент plum→flame (background-clip:text).

## Контент по карточкам
| # | Контент | Визуал |
|---|---|---|
| 1 | **15** — активных читателей | иконка людей, гигантская цифра |
| 2 | **3** — языка → EN / FR / PL / JP | иконка глобуса, чипы языков |
| 3 | **Не сырой AI** — фрагменты → стиль → перевод → проверка | вертикальный конвейер из 4 пилюль со стрелками |
| 4 | **19 / 30** — длинных отрывков — за человеком | прогресс-бар 63% (19 из 30) |
| 5 | **522 vs 250** — фрагменты: человек vs AI | две колонки-бара (высоты пропорциональны), оранжевый=человек, фиолетовый=AI |
| 6 | **Проблема — в неровности** — сильный абзац → неловкая фраза | волнистая линия качества с провалом; фиолетовая точка = сильный абзац, оранжевая = неловкая фраза |
| 7 | **Главный вывод:** AI пишет гладко, но в романе именно **мелочи решают всё** | оранжевая рамка + иконка лампочки |

## Анимация (постоянная, цикличная — живёт в HTML и MP4; на PNG заморожена)
| # | Что движется |
|---|---|
| 1 | градиент цифры «15» переливается, иконка «дышит» |
| 2 | подсветка бежит по чипам EN→FR→PL→JP, стрелка «→» покачивается, цифра переливается |
| 3 | волна подсветки идёт по конвейеру сверху вниз, стрелки пульсируют каскадом |
| 4 | блик бежит по заполненной части прогресс-бара, «19» переливается |
| 5 | столбики вырастают с нуля, цифры и «vs» появляются, затем цикл повторяется |
| 6 | пунктир волны течёт, светящаяся точка бежит по волне (offset-path), оранжевая точка даёт «пинг»-кольца |
| 7 | рамка мягко светится, лампочка мигает, «мелочи решают всё» подсвечивается |

## Критерии (tests/verify.mjs — 55 проверок)
1. Ровно 7 карточек `#card-1..7`, каждая **1080×1350**.
2. Тёмный фон на всех, логотип AIT на каждой.
3. JetBrains Mono загружен.
4. Все фразы таблицы присутствуют в DOM.
5. Вёрстка: контент в кадре (поле 36px), текст не обрезан.
6. Палитра чистая: только flame/plum.
