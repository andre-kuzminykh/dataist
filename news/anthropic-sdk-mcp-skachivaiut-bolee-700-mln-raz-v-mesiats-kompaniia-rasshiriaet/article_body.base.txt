# Anthropic расширяет MCP для самостоятельной работы ИИ-агентов

## Задачи и уточнения без постоянного контроля

Функции Tasks и Elicitation стали общедоступными после открытого тестирования в октябре. Tasks позволяет серверу выполнять длительную работу в фоновом режиме и сообщать результат, когда он готов. С помощью Elicitation текущий процесс может приостановиться и запросить у пользователя конкретные недостающие сведения. Обе функции дают MCP-серверам больше самостоятельности.

## Навыки и передача файлов

В открытом бета-тестировании находится Skills over MCP. Эта функция позволяет связывать инструменты серверов с навыками, которые помогают Claude выполнять длинные многоэтапные задачи. По данным Anthropic, навыки включают лучшие практики, пошаговые сценарии работы и инструкции, адаптированные под конкретную учётную запись пользователя или организации.

Anthropic также готовит поддержку загрузки файлов. После запуска Claude сможет напрямую передавать MCP-серверам PDF-файлы, таблицы и изображения. Компания планирует вскоре добавить эту возможность в Claude и Claude Code для подписчиков Pro, Max и Ultra, а также для подходящих клиентов Team и Enterprise.

## Техническая основа для масштабирования MCP

Новые функции опираются на технические изменения, которые Anthropic внедряла в течение последнего года. Tool Search сокращает потребление памяти во время активных диалогов: описания отдельных инструментов загружаются только тогда, когда они нужны. По данным компании, в конфигурациях с несколькими серверами это может снизить использование контекстного окна более чем на 85%.

Текущая спецификация MCP не требует постоянного хранения данных сеанса и работает во всех продуктах Claude. Anthropic стремится упростить разработку серверов и повысить надёжность их работы по мере роста нагрузки.

Для корпоративных клиентов компания выпустила Enterprise Managed Auth. Администраторы могут один раз одобрить поддерживаемые серверы, после чего сотрудники подключаются к ним автоматически. MCP Apps позволяет разработчикам встраивать полноценные интерфейсы в Claude — рядом с активным чатом или в полноэкранном режиме.

## Как развивался протокол

В ноябре 2024 года Anthropic представила Model Context Protocol — открытый стандарт, который даёт ИИ-помощникам единый способ доступа к рабочим инструментам, средам разработки и другим источникам данных. В марте 2025 года генеральный директор OpenAI Сэм Альтман объявил, что компания будет использовать стандарт конкурента в своих продуктах. В мае 2025 года OpenAI обновила Responses API, добавив поддержку удалённых MCP-серверов. В январе 2026 года исследователи Шанхайской лаборатории искусственного интеллекта представили Science Context Protocol (SCP), созданный по образцу MCP.

По оценке Dataist, Anthropic развивает MCP сразу в двух направлениях: упрощает подключение к инструментам и добавляет механизмы для длительной работы агентов без постоянного участия пользователя. При этом часть новых возможностей ещё не доступна всем: Skills over MCP остаётся в открытом бета-тестировании, а поддержку файлов компания только планирует запустить.
