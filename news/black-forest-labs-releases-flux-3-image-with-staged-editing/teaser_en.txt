Black Forest Labs has released Flux 3 Image, an image-editing model designed to make changes in stages while leaving the rest of an image untouched. API access is available at half price through October 8, and companies can license commercial weights to run and fine-tune the model on their own infrastructure. An open-weights version is expected in the coming weeks, putting the release alongside Ideogram’s recently announced version 4.5 editing model, which is also planned for an open-weights release.
