# Microsoft обновила Copilot: постоянный ИИ-агент и хостинг приложений

В рамках обновления Microsoft представила три направления:

1. **Home** — объединяет Chat и Cowork.
2. **Code** — создаёт приложения по письменным инструкциям.
3. **Autopilot** — постоянный ИИ-агент, который следит за проектами и взаимодействует с сотрудниками.

Компания также представила управляемый хостинг приложений и расширила инструменты контроля расходов на ИИ.

Для корпоративных клиентов обновление сводится к двум вопросам: какую часть работы можно передать ИИ и как контролировать и оплачивать задачи, которые продолжаются в фоновом режиме. Microsoft описала значительную часть планов, но не раскрыла важные детали ценообразования.

На презентации 23 сентября, проведённой для VentureBeat перед анонсом, генеральный директор Microsoft Сатья Наделла сказал, что у каждого агента должна быть собственная идентичность, а все его действия необходимо отслеживать.

## Постоянные задания в Autopilot

Autopilot — новое название Scout, прежней инициативы Microsoft по созданию персонального агента. Пользователь задаёт ему цель и роль, а система поддерживает для агента отдельную идентичность, память, вычислительную среду и рабочее пространство внутри корпоративной среды Microsoft 365.

По словам Microsoft, агент может отслеживать обсуждения, запрашивать обновления, выполнять регулярные обязанности и возвращаться к проекту через несколько дней. Сотрудники взаимодействуют с ним через Teams, Outlook и документы — в том числе упоминают его так же, как другого участника.

Autopilot рассчитан на постоянные задачи. Например, пользователь может поручить ему проверку поставщика: агент организует подготовку, назначит встречи и запросит недостающую информацию по мере развития проекта.

Microsoft показала этот сценарий на примере розничной компании. Агент Autopilot по имени Dot следил за подготовкой к «чёрной пятнице», собирая сведения из электронной почты, обсуждений в Teams, данных об остатках в Dynamics 365 и таблиц. Он обнаружил проблему с поставкой, которая затронула 18 магазинов, подключил сотрудников к обсуждению и сообщил, что группа решила вопрос.

Демонстрация показывает предполагаемый рабочий процесс Microsoft, но не подтверждает, насколько надёжно Autopilot будет справляться с похожими ситуациями в реальных внедрениях клиентов.

У Scout были технологии, созданные за пределами Microsoft. Представляя его в июне, компания назвала базовой технологией проект с открытым исходным кодом OpenClaw и описала добавление корпоративных средств управления идентичностью и доступом. В пятничных материалах подтверждается переименование Scout в Autopilot, но не объясняется, как изменилась внутренняя архитектура.

Agent 365 предоставляет для Autopilot разрешения, журналы аудита и административные настройки. Это важно, когда программа начинает связываться с людьми или работать с корпоративными данными. Однако документы запуска не содержат полной политики согласования действий по отдельным шагам и не объясняют, как администраторам обрабатывать все виды неудачных операций.

## Home объединяет работу с Office

Home сочетает быстрые диалоги с более продолжительными заданиями, которые выполняются через Cowork. Microsoft также планирует автоматическую маршрутизацию: пользователь описывает желаемый результат, а Copilot сам выбирает подходящую возможность.

Office в Copilot объединяет редактирование и совместную работу с документами Word и PowerPoint, а также работу в Excel. По словам Microsoft, пользователи смогут создавать и изменять те же документы, над которыми их коллеги работают в отдельных приложениях Office, сохраняя синхронизацию общих файлов.

В демонстрации менеджер по продукту Моник Смит собрала рекомендацию в Excel, проверила вклад коллег в документе Word и создала презентацию на основе этих материалов. В рабочем процессе использовались отслеживание изменений и последующее редактирование слайдов внутри Copilot.

Ещё одна запланированная функция Home — Today — собирает сигналы из электронной почты, календарей, обсуждений и заданий. Она может подготовить проект последующего сообщения или предложить изменить событие в календаре, после чего пользователь проверяет результат и решает, что с ним делать. Microsoft также планирует перенести этот сценарий в Outlook и Teams.

Так Microsoft присоединяется к конкурентам, которые объединяют собственные интерфейсы. 16 сентября Anthropic объявила о совмещении чата Claude и Cowork, а также инструментов для работы с документами и слайдами. Её система тоже может продолжать порученные задачи после закрытия ноутбука.

Преимущество Microsoft связывает эти взаимодействия с файлами Office, корпоративными системами и административными политиками, которые уже используют клиенты. Компаниям, сравнивающим продукты, придётся проверить, как каждый из них работает с совместным редактированием, разрешениями и завершёнными заданиями в их среде.

## Code создаёт приложения и размещает их

Code расширяет Copilot для сотрудников, которым нужен собственный инструмент под конкретную задачу. Пользователь может описать приложение, панель мониторинга, автоматизацию или виджет для рабочего стола, а Copilot сгенерирует реализацию.

Microsoft говорит, что Code использует общую базовую технологию с GitHub Copilot, а также учитывает корпоративный контекст и подключённые сервисы. Профессиональные разработчики смогут продолжать работать с GitHub Copilot, тогда как бизнес-пользователи будут создавать приложения через интерфейс Copilot.

Copilot уже позволял создавать приложения через App Builder, представленный в октябре 2025 года для участников Frontier. Сотрудники могли генерировать интерактивные приложения и делиться ими с коллегами. Такие приложения уже использовали инфраструктуру Microsoft: размещались в среде Power Platform, а данные хранились внутри приложения или в списках SharePoint. Отдельно организовывать хостинг не требовалось.

Новый анонс расширяет этот подход. В прежней документации App Builder запрещались вызовы внешних API, а пользователи не могли просматривать или напрямую изменять сгенерированный код. Новый предложенный Microsoft runtime поддерживает редактируемый код и управление версиями через Git, а SDK открывает управляемый Microsoft хостинг для совместимых сторонних инструментов разработки. Платформой управляет Microsoft, а администраторы клиента определяют права доступа и разрешённые подключения к данным.

В одной демонстрации приложение для отдела продаж начинало работу с таблицы, подключалось к корпоративным данным и позволяло менять предположения во время разговора с клиентом. В другом примере система объединяла сведения об аккаунте с внешними сигналами в персональном рабочем пространстве.

На презентации исполнительный вице-президент Microsoft по Copilot Джейкоб Андреу сказал, что размещение и совместное использование приложения должно стать таким же простым, как сохранение и передача документа Word.

Основная инфраструктура получила название Copilot Managed Runtime. Это управляемая Microsoft платформа, которая размещает приложения внутри границ организации Microsoft 365. Она поддерживает приложения, созданные через Copilot Studio, Cowork или Code. SDK открывает такой же путь развёртывания для совместимых внешних инструментов и профессиональных разработчиков.

Entra предоставляет службы идентификации, а администраторы определяют разрешённые подключения к данным и конечные точки. Git отслеживает исходный код и версии. Разработчики могут использовать SDK и инструменты командной строки для настройки проектов, предварительного просмотра изменений и развёртывания обновлений. При этом существующее приложение остаётся доступным во время разработки.

Администраторы получают единый список приложений с информацией о доступе, активности, состоянии и соблюдении политик. Microsoft предлагает использовать такую общую рабочую среду по мере роста числа приложений, которые сотрудники могут создавать самостоятельно.

## Microsoft расширяет контроль расходов на ИИ

Чем больше задач выполняется автономно, тем больше возможностей для начисления платы за использование. Дополнения Microsoft к FinOps расширяют управление расходами Agent 365 на Autopilot, Code и управляемый runtime. В октябре к ним должны добавиться агенты Copilot Studio.

Уже существующие настройки позволяют администраторам распределять бюджеты, устанавливать ограничения и получать уведомления. Microsoft говорит, что тарифицируемые сервисы остаются отключёнными, пока администраторы не разрешат доступ через политики расходов.

Новые функции включают доступ к моделям для отдельных групп — сначала для Cowork. Администратор может ограничить доступные семейства моделей, а вместе с ним и выбор, который доступен автоматической маршрутизации.

Сотрудники смогут видеть количество потраченных кредитов, оставшийся лимит и предыдущую активность. Организации смогут управлять политиками расходов и отслеживать балансы через API Microsoft Graph, а запросы на дополнительные кредиты направлять в существующие процессы согласования.

Microsoft также вводит отчётность Cowork, которая должна связывать потребление ресурсов с полезными результатами. Это может помочь руководителям решать, какие рабочие процессы стоит развивать, но представленные материалы не объясняют методику измерений настолько подробно, чтобы считать такие панели доказательством финансовой отдачи.

Компания расширяет и контекст, доступный её ИИ-инструментам:

- **Fabric IQ** добавляет в Chat и Cowork контекст корпоративных данных.
- **Work IQ** получит подключения к Power Platform и Dynamics 365, что добавит в Copilot новые деловые сведения.
- **Общий реестр плагинов** даст администраторам единое место для одобрения расширений Microsoft, партнёров и внутренних команд.

## Цены и доступность

На момент публикации Microsoft не предоставила подробные цены на новые возможности. Представленных данных недостаточно, чтобы рассчитать стоимость продолжающегося задания Autopilot, проекта Code или приложения, работающего на управляемом хостинге.

VentureBeat запросил у Microsoft дополнительные сведения о ценах и собирается обновить материал после ответа компании.

Объявленная схема оплаты разделяет подписки на обычные взаимодействия с Copilot и плату за использование при более масштабной работе агентов. Microsoft относит Autopilot, Cowork и Code к тарифицируемым по потреблению возможностям вместе с передовыми моделями Astra и Fable.

Текущие цены в США дают представление об уровнях лицензирования:

- Входит без дополнительной платы для подходящих подписчиков Microsoft 365, использующих учётные записи Entra. Работа агента может тарифицироваться отдельно по потреблению.
- $30 в месяц за пользователя при ежегодной оплате, сверх подходящей подписки Microsoft 365.
- $21 в месяц за пользователя по стандартной цене; сейчас рекламная цена составляет $18 при ежегодной оплате в рамках акции на первый год. Требуется подходящая подписка Business, поддерживается до 300 пользователей.
- $99 в месяц за пользователя при ежегодной оплате. Пакет объединяет E5, Copilot, Agent 365 и Entra Suite.
- $15 в месяц за пользователя при ежегодной оплате как отдельное предложение; также входит в E7.

Эти цифры взяты из материалов Microsoft о ценах на корпоративный Copilot, бизнес-тарифах, сравнении планов Microsoft 365 и рекомендациях для партнёров по лицензированию. Акция для Business распространяется на подходящие покупки до 31 декабря 2026 года, а скидка действует только первый год.

Cowork уже работает по переменной схеме оплаты. При общем запуске 16 июня Microsoft потребовала подписку Copilot и оплату использования. Тариф составлял $0,01 за каждый кредит Copilot, при этом были доступны скидки за предварительную покупку пакетов.

Кредит — это единица расчёта, поэтому тариф не означает, что вся задача стоит один цент. Microsoft объяснила, что сумма зависит от модели, извлечённого контекста, вызванных инструментов и времени выполнения. Начисление платы началось 16 июня, а для подходящих пользователей Frontier, которые подключились раньше, переходный период продлился до 1 июля.

Предыдущие коммерческие условия Scout были менее конкретными. В июньском уведомлении для партнёров Microsoft описала зависимость цены от использования и пообещала дополнительные рекомендации по расходам. Поэтому подписку E7 за $99 нельзя считать универсальной ценой Scout или Autopilot. В существующей документации по настройке Scout среди необходимых условий также указаны лицензии Microsoft 365 Copilot и GitHub Copilot Business или Enterprise. Пятничные материалы не объясняют, как эти прежние требования соотносятся с Autopilot.

Microsoft сообщает, что управление расходами в Agent 365 входит в облачные подписки. Это не означает, что хостинг runtime предоставляется бесплатно или что выполнение агентов не ограничено.

Доступ к функциям будет открываться поэтапно:

- Home и интеграция с Office начнут становиться доступны участникам Frontier в течение ближайших недель; интеграция с Office также будет распространяться среди обычных пользователей.
- Code должен появиться в Frontier в конце сентября, после чего начнётся более широкий запуск.
- Позже в 2026 году Microsoft планирует расширить предварительный доступ на подписчиков Microsoft 365 Premium или Pro.
- Закрытое тестирование Autopilot расширится в конце месяца.
- Управляемый runtime и SDK перейдут в публичное предварительное тестирование.
- Закрытое тестирование Today запланировано на октябрь.
- Интеграция Fabric IQ с Cowork и Chat уже переходит в общий доступ.
- Расширение Work IQ станет доступно в публичном предварительном тестировании в течение следующего месяца.
- Общий реестр плагинов должен перейти в общий доступ к концу сентября.
- Общие взаимодействия с Copilot через символ @ в Teams также начнут закрытое тестирование в конце месяца.

Для покупателей эти сроки и отсутствие точных тарифов важны при оценке предложения. Microsoft расширяет набор задач, которые можно передавать Copilot, но компаниям ещё предстоит понять, удастся ли совместить дополнительную автономность с предсказуемыми расходами и стабильными результатами.
