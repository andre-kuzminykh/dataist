Claude can now embed text, buttons, and other webpage elements in complex graphics and 3D scenes. HTML-in-Canvas keeps them interactive: text can be selected and copied, and buttons can be clicked. The feature currently works in Chrome and Edge from version 157 onward, and in Claude desktop apps from version 5.11492 onward. Safari and Firefox do not yet support it.

# Claude creates interactive graphics with real HTML elements

## How the technology works

Ordinary HTML elements can be clicked, selected, and read by screen readers, but they are difficult to transform visually. Canvas, by contrast, lets developers draw arbitrary graphics, but browsers treat them as flat images: text inside cannot be selected, and links cannot be opened.

HTML-in-Canvas lets developers place real webpage elements inside canvas graphics without losing the ability to interact with them.

Felix Rieseberg, who works on Claude at Anthropic, wrote on X that the feature lets Claude create unusual and beautiful websites. He said the technology reminded him of the Flash era.

A demo page shows 15 design variations: websites rendered as knitting patterns, 3D cubes, and layers spread out in space. The content remains real text that can be selected and copied.

## Where HTML-in-Canvas works

Google is developing HTML-in-Canvas as a web standard intended to preserve the interactivity and accessibility of content. The feature is available in Chrome and Edge from version 157 onward, as well as in Claude desktop apps from version 5.11492 onward. Safari and Firefox do not yet support it.

To get Claude to use this capability, users need to ask for it directly in the prompt. Recently, Claude Fable 5.2 also created a photorealistic painting by applying brushstrokes one by one with code it wrote in Python.

Dataist's take: HTML-in-Canvas makes it possible to combine complex visual design with selectable text and working page elements. For now, access is limited to Chrome and Edge browsers and Claude desktop apps; Safari and Firefox do not support it.
