# Adobe добавила ИИ-функции в Creative Cloud и выпустила MCP

[FIGURE:0]

## Новые инструменты Firefly

В приложении Firefly появилась функция Builder: она позволяет создавать макеты для показа идей. Сейчас инструмент находится в закрытом бета-тестировании и нацелен на задачи, для которых используют Figma.

Также Adobe добавила инструмент для создания графиков в фирменном стиле и редактор изображений. С его помощью можно менять отдельную часть картинки, не затрагивая остальные объекты.

В Firefly появился инструмент на базе ИИ для сборки видео из клипов, изображений, звуковых эффектов и других элементов. Adobe также меняет своего творческого ИИ-агента: он будет работать постоянно и самостоятельно собирать больше контекста о проектах, чтобы быть готовым к действиям. Для быстрых операций предусмотрены, например, удаление фона и создание миниатюры для видео.

## Обновления приложений Adobe

На MAX компания продолжила добавлять ИИ-функции в свои приложения. Photoshop получит инструмент для изменения освещения и ползунки для управления генеративными стилями с помощью промтов. В Premiere появятся система цветокоррекции для профессионалов и удаление объектов из видео. Lightroom научится исправлять моргание на фотографиях и удалять дефекты кожи.

Adobe уже предлагает сторонние модели от Google, Runway, ElevenLabs, Black Forest Labs, OpenAI, Kling и ByteDance. Topaz Labs, одна из недавних покупок компании, выпускает две модели для изображений:

- **Wonder 4** — для увеличения разрешения и шумоподавления.
- **ImageHDR** — для преобразования обычных изображений в HDR.

## MCP для Creative Cloud

Adobe уже интегрировала ChatGPT и Claude, чтобы пользователи могли обращаться к некоторым функциям её продуктов. Новый локальный MCP должен открыть доступ к большему числу функций приложений Creative Cloud через сторонние чат-боты.

Вице-президент Adobe Дипа Субраманиам рассказала TechCrunch, что компания пока определяет, какие именно возможности предоставлять через протокол, и будет ориентироваться на отзывы пользователей. Сейчас MCP включает набор конечных точек и функций для Illustrator, Photoshop, After Effects и Premiere. Adobe намерена следить за тем, как люди используют эти инструменты и какие задачи решают, а затем добавлять новые возможности. По словам Субраманиам, компания не стремится заранее ограничивать доступ через MCP: цель — поддерживать творческий рабочий процесс пользователей.

В прошлом месяце сооснователь конкурирующей Figma Дилан Филд заявил на мероприятии в Индии, что MCP — несовершенный стандарт, который больше выгоден ведущим лабораториям, разрабатывающим ИИ.

По оценке Dataist, MCP может связать функции Adobe с рабочими процессами в сторонних чат-ботах, но набор доступных возможностей пока будет меняться. Компания прямо говорит, что определяет его с учётом пользовательских отзывов, а значит, окончательные границы интеграции ещё не установлены.
