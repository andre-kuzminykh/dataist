## What the API returns

OpenAI cites damage detection in photos, routing customer inquiries and document classification as possible uses. The API also supports a mode that stores no data and use that meets HIPAA requirements in the US and Europe.

[INFO:chips] photo damage | inquiry routing | document classification

The launch follows a modest burst of interest in “decision-making models” that Jave kicked off in mid-September. The source does not specify how Decisions API performs or compare it with other ways to build these workflows.

## Three paid tiers

OpenAI has replaced five paid API tiers with three: Build, Launch and Grow. Organizations move automatically to the next tier when their total purchased credits reach a set threshold. Monthly usage limits are $500, $5,000 and $200,000, respectively.

I think the more interesting question is what the API’s simplified output hides: the announcement describes the answer formats and example tasks, but gives no accuracy figures. For applications such as routing or damage detection, a clean yes-or-no output is useful only if teams can judge when to trust it. The new tiers make spending easier to navigate; they do not answer that question.
