# OpenAI enters cybersecurity with two Daybreak products

## Testing applications and fixing code

Daybreak Red Team analyzes a web application’s source code and context to identify possible attack paths. The tool also checks vulnerabilities reported through bug bounty programs or code scanners, and tests fixes. The product is available in early access.

Nancy Wang, head of Cyber-Applied AI, said the tool is intended to combine the speed of continuous automated scanning with the depth of testing performed by penetration testers.

Daybreak Defense Factory automates defensive work: AI agents search a company’s codebase for vulnerabilities and prepare fixes. Developers receive ready-to-review code merge requests with fixes and accompanying tests, which they can review and approve.

Both products use OpenAI’s latest cyber model, GPT-6 Cyber.

Dataist’s take: Daybreak covers two stages of vulnerability work: finding issues and preparing fixes. Developers still have final approval over code changes, and Red Team is currently available only in early access.
