# Microsoft обновляет Copilot и запускает агента Autopilot

[INFO:chips] Home | Code | Autopilot

## Что изменится в Copilot

Autopilot задуман как постоянно работающий помощник для бизнеса. Каждый его экземпляр получает:

- собственный облачный компьютер;
- рабочее пространство;
- хранилище;
- учётную запись.

Это позволяет агенту без участия человека отслеживать каналы Teams, координировать оценку поставщиков и выполнять регулярные задачи.

Запустить Autopilot можно через упоминание `@` в Teams, Outlook или документах. После этого агент продолжает работать в облаке, даже если пользователь вышел из системы. По словам главы маркетинга ИИ-направления Microsoft Джареда Спатаро, Autopilot использует Microsoft IQ, чтобы понимать, как на самом деле устроена работа организации. В систему также входят права доступа, аудит и управление.

Раздел Code позволит людям без навыков разработки создавать приложения, панели управления и автоматизации с помощью естественного языка. Он использует ту же технологию, что и GitHub Copilot, а запуск происходит в защищённой среде Copilot Managed Runtime.

Home объединит чат и совместную работу. В будущем в нём появится функция Today: она будет собирать электронную почту, календарь, сообщения Teams и задачи на одной панели. Закрытое тестирование Today начнётся в октябре. Word, Excel и PowerPoint теперь встроены непосредственно в Copilot.

## Оплата по использованию

Microsoft переводит Autopilot, Code и Cowork с фиксированной цены на оплату по фактическому использованию — по схеме, похожей на работу ChatGPT Enterprise после исчерпания определённой квоты. Обычная лицензия Copilot теперь покрывает только чат и интеграции с приложениями Office. Как компания уже сообщала ранее, Microsoft сокращает субсидирование использования ИИ через тарифы с фиксированной оплатой.

Для интеграций с Office автоматический маршрутизатор будет выбирать модель для каждого запроса с учётом точности, скорости и стоимости. Microsoft, вероятно, будет отдавать предпочтение собственным моделям: они оптимизированы для эффективности, но не могут сравниться по качеству с передовыми моделями.

ИТ-администраторы смогут задавать, какие семейства моделей доступны определённым группам пользователей. По данным Microsoft, функции с оплатой по использованию также будут обращаться к передовым моделям, включая Astra от OpenAI и Fable от Anthropic. Новые инструменты FinOps-for-ИИ должны помочь компаниям контролировать расходы на ИИ.

## Выход для пользователей

Наделла планирует со временем выпустить Autopilot и для обычных пользователей. Он ссылается на более чем 100 миллионов потребителей, подписанных на сервисы экосистемы Microsoft. В корпоративном сегменте Наделла считает рынок агентов гораздо крупнее рынка облачных сервисов, а для обычных пользователей агенты, по его мнению, могут заменить существующих посредников.

Home и Code появятся в ближайшие недели в рамках программы Microsoft Frontier. Autopilot запустят в конце сентября в режиме закрытого тестирования. Code должен стать доступен позднее в этом году подписчикам Microsoft 365 Premium и Pro.
