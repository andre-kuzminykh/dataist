# Hermes Agent позволит сотрудникам делиться навыками ИИ внутри компании

## Работа в Microsoft Teams

Сотрудники смогут передавать Hermes задачи и просматривать результаты в чате. Настольное приложение Hermes Agent доступно в Microsoft Store.

Агент автоматически превращает успешно выполненные рабочие процессы в повторно используемые навыки: каждый состоит из описания и кода. Функция Collective Wisdom позволяет после проверки делиться этими навыками с коллегами. Собранные знания остаются внутри компании и не попадают в данные для обучения ИИ-провайдеров.

## Положение Nous Research

Nous Research входит в портфель M12 — венчурного фонда Microsoft. По данным компании, Hermes Agent — самый широко используемый открытый агент на OpenRouter; он обрабатывает почти два триллиона токенов в день.

С начала этого года Microsoft также поддерживает OpenClaw — конкурирующего агента с открытым исходным кодом для локального запуска на компьютерах с Windows. Nous Research называет себя одной из ведущих американских организаций в сфере открытого кода, работающих в противовес усилиям Китая в области ИИ. Недавно компания вместе с Arete-27B провела файн-тюнинг версии Qwen3.8-27B от Alibaba на «западных ценностях».

По оценке Dataist, Collective Wisdom превращает индивидуальные находки сотрудников в общие рабочие навыки, сохраняя их внутри компании. Однако публикацию навыков предваряет проверка, а заявленные масштабы использования Hermes Agent основаны на данных самой Nous Research.
