# Anthropic добавила в Claude Code плагины для изменения инструмента изнутри

## Где работают моды

Anthropic выложила примеры модов на GitHub. Они запускаются с разрешениями пользователя и не изолированы в песочнице, поэтому компания советует устанавливать их только из надёжных источников. Моды работают в командной строке и настольном приложении, а в расширении для VS Code — частично. Организации могут ограничивать список модов, которым разрешено загружаться.

## Первый официальный плагин

Первый официальный плагин называется «You Should Know». Он запускает отдельного агента, который следит за ответами Claude и отправляет сообщение «На заметку», если замечает важную информацию, которую пользователь мог пропустить.

Чтобы включить плагин, выполните команду:

`/plugin enable cc-plugin-you-should-know@builtin`
