# Hugging Face разрешила оплачивать сервисы через Google Cloud

## Какие расходы можно перенести в Google Cloud

Hugging Face используют, чтобы находить, создавать и запускать открытые модели. Платформа позволяет размещать закрытые модели и наборы данных, запускать вычислительные задачи на GPU через Jobs, развёртывать модели с инференс Endpoints, обращаться к тысячам моделей через инференс Providers и размещать демки на GPU Spaces.

Связав организацию Hugging Face с Google Cloud Marketplace, компания получает три возможности:

- Счёт за Hugging Face добавляется к существующему счёту Google Cloud.
- Покупки проходят через уже настроенные платёжный аккаунт и процесс закупок Google Cloud.
- Через Marketplace оплачиваются подписки Team и Enterprise, вычисления по факту использования в Jobs, инференс Endpoints, инференс Providers и GPU Spaces, расширение квоты ZeroGPU и дополнительное хранилище по публичным ценам Hugging Face.

Настроить оплату может администратор организации Hugging Face.

## Как подключить организацию

Сначала нужно найти Hugging Face Hub в Google Cloud Marketplace, выбрать проект Google Cloud и нажать Subscribe. На странице подписки следует указать платёжный аккаунт, принять условия и подтвердить заказ. Затем Google Cloud предложит завершить настройку аккаунта Hugging Face: нужно нажать Sign up with Hugging Face.

[FIGURE:0]

После перехода на Hugging Face администратор выбирает организацию для связи с Google Cloud и подтверждает выбор. В списке отображаются только организации, где у пользователя есть права администратора.

[FIGURE:1]

[FIGURE:2]

Затем пользователь попадает в платёжные настройки организации. В разделе способов оплаты появляется привязанный аккаунт Google Cloud со статусом ожидания.

[FIGURE:3]

До одобрения подписки командой Hugging Face платные услуги продолжают списываться с прежнего способа оплаты организации, если он настроен. Каждый запрос на подписку через облачный маркетплейс проверяется до того, как оплата начнёт проходить через Google Cloud.

[FIGURE:4]

После одобрения Hugging Face присылает письмо о привязке аккаунта Google Cloud к организации. Если у организации уже сохранена банковская карта, переход на оплату через Marketplace происходит в начале следующего расчётного периода. Организации на бесплатном тарифе без карты обычно переключаются сразу — платное использование начинает учитываться через облачный маркетплейс немедленно.

Проверить подключение можно в платёжных настройках: аккаунт Google Cloud будет указан как активный способ оплаты организации.

[FIGURE:5]

## Что меняется после подключения

Все участники организации могут пользоваться вычислительными сервисами Hugging Face, а расходы отображаются в счёте Google Cloud. При этом действуют несколько условий:

- Google Cloud заменяет банковскую карту как способ оплаты организации. Расходы учитываются и передаются в Google Cloud, поэтому пополнять баланс организации, подключённой через Marketplace, нельзя.
- Включённые в подписки Team и Enterprise кредиты сохраняются: сначала расходуются они, а затем в Google Cloud передаются начисления за использование сервисов сверх лимита.
- Использование можно отслеживать в платёжном разделе настроек организации, а списания — в отчётах Billing консоли Google Cloud.
- Подключение и отключение оплаты через Marketplace фиксируются в журнале аудита организации.

По оценке Dataist, эта схема в первую очередь упрощает корпоративные закупки для компаний, уже оплачивающих Google Cloud: услуги Hugging Face проходят через привычный платёжный аккаунт. Однако до одобрения подписки действует прежний способ оплаты, а пополнять баланс после перехода на Marketplace нельзя.
