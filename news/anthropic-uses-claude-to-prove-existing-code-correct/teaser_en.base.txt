Anthropic says Claude has generated formal proofs for existing code, turning software verification into a task an AI can do with limited human review. Working with Theorem, the company’s Frontier Red Team used tests from 123 open-source libraries in Google’s OSS-Fuzz project to produce about 180 million lines of proof code in a few weeks. The result is promising, but its guarantees apply only under narrow conditions—and the project’s cost remains undisclosed.
