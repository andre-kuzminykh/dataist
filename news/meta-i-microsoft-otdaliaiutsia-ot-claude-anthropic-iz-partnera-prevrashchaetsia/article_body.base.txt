# Meta и Microsoft сокращают использование Claude на фоне роста Anthropic

В Meta число пользователей Claude Code упало примерно с 60 000 до 30 000. На это повлияли и увольнения, и продвижение собственных инструментов — Muse Code и MetaCode. За один 28-дневный период Meta потратила только на Claude Code более $105 млн. Ещё в июне компания начала сокращать расходы на ИИ.

Сокращение затрат — одна из возможных причин, но не единственная. Meta незачем продолжать поддерживать Anthropic, если та продаёт конкурирующие продукты. Кроме того, по сообщениям, Meta хотела ограничить доступ Anthropic к своим обучающим данным. При этом трудно не заметить иронию: Meta беспокоится, что кто-то другой использует её данные.

Anthropic быстро растёт и становится проблемой для компаний, давно работающих на рынке. Microsoft тоже есть о чём беспокоиться: такие инструменты, как Claude Cowork и ChatGPT Work, всё больше конкурируют с Office.
