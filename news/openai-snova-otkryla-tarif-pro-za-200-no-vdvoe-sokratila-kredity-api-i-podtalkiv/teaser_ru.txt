OpenAI снова открыла ежемесячную подписку Pro за $200 для новых пользователей, но вдвое уменьшила количество кредитов API на каждый потраченный доллар. По словам сотрудника компании Тибо Сотсьо, подписчики всё равно смогут делать больше, чем месяц назад: на этой неделе вышли GPT-6 Sol и GPT-6 Luna, API которых стоит вдвое дешевле, чем у предшественников. Ограничение на использование в течение пяти часов отменили: недельный лимит теперь можно распределять как угодно.
