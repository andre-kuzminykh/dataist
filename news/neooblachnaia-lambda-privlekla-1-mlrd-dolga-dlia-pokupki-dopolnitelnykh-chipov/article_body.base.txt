# Lambda привлекла $1 млрд долга на закупку чипов Nvidia

Неооблачная компания Lambda, которая закупает вычислительные чипы и сдаёт их бизнесу в аренду, привлекла $1 млрд частного краткосрочного долга. Средства пойдут на покупку ИИ-чипов Nvidia, которые Lambda затем передаст в аренду Microsoft, сообщает Bloomberg. Сделку организовал JP Morgan Chase. Условия финансирования показывают, что Lambda рассчитывает быстро установить оборудование и начать получать выручку, чтобы вскоре погасить долг из этих поступлений. Это очередной заём компании для создания GPU-инфраструктуры под конкретных клиентов.

[FIGURE:0]

В мае Lambda закрыла обеспеченную кредитную линию на $1 млрд. На этой неделе компания также объявила о привлечении займа на $926 млн для финансирования Nvidia GB300 — одной из новых моделей чипов Nvidia. Их установят в рамках проекта, который Lambda обязалась выполнить по контракту с Nvidia.

[INFO:facts] $1 млрд :: частный краткосрочный долг | $1 млрд :: обеспеченная кредитная линия в мае | $926 млн :: заём на Nvidia GB300 | $1,5 млрд :: венчурные инвестиции в ноябре

Новый частный долг на $1 млрд появился на фоне переговоров Lambda о раунде перед выходом на биржу объёмом $3 млрд. В ноябре прошлого года компания привлекла $1,5 млрд венчурного капитала при оценке после сделки в $5,43 млрд, следует из данных PitchBook.

Lambda — не единственная компания, которая использует заёмные средства для финансирования роста ИИ-рынка. По данным, собранным Bloomberg, банки и технологические компании по всему миру уже привлекли более $400 млрд долгового финансирования, связанного с ИИ, с начала 2026 года.
