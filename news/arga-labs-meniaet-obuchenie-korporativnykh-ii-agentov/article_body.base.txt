# Arga Labs привлекла $10 млн на обучение ИИ-агентов

Arga Labs привлекла $10 млн в посевном раунде, который возглавила General Catalyst при участии Box Group, Emergence, Gradient и SV Angel. Стартап создаёт среды для обучения ИИ-агентов работе с корпоративными программами — Salesforce, Workday и почтовыми клиентами. Вместо обычной конечной точки API Arga воспроизводит полноценный цифровой двойник приложения с системами разрешений и уведомлениями о событиях. Это позволяет сбрасывать состояние среды, запускать множество копий одновременно и обучать агентов на сложных сценариях взаимодействия между разными программами.

## Цифровые двойники корпоративных программ

Arga Labs разрабатывает среды для обучения ИИ-агентов работе с корпоративным ПО. В большинстве тестовых сред используется конечная точка API без состояния. Стартап создаёт полномасштабную цифровую копию программы, сохраняя её систему разрешений и уведомления о событиях.

Такой подход должен помочь обучать агентов взаимодействовать сразу с несколькими системами. Генеральный директор и сооснователь Arga Labs Phillip Li приводит пример: потенциальный клиент создаёт запись о новом клиенте в Salesforce, а его коллега отдельно связывается с той же компанией через HubSpot.

Агенту в таком сценарии нужно определить, что речь идёт об одной и той же компании, проверить, не отправлялось ли письмо дважды, и выбрать, кому из двух потенциальных клиентов его адресовать. По словам Li, агентные системы пока испытывают трудности с подобной неоднозначностью, а инструменты Arga Labs должны помочь им улучшить результаты.

## Как работает обучение

Обычно агента можно обучать такой задаче с помощью обучения с подкреплением: запускать один и тот же сценарий десятки тысяч раз и оставлять только успешные стратегии. Корпоративные программы делают такой подход почти невозможным. Salesforce или Outlook нельзя легко вернуть в исходное состояние перед новым запуском, а тем более быстро создавать их копии.

Arga Labs решает проблему, создавая цифровую копию программы. Она воспроизводит структуру исходного ПО примерно так же, как манекен для испытаний на столкновение воспроизводит человека. Поскольку компания полностью контролирует среду, её можно быстро сбрасывать и менять.

Кроме того, Arga может одновременно запускать множество сред и обучать агентов сложным взаимодействиям между разными программами. В перспективе среда должна воспроизводить весь рабочий контекст человека: отдельные задачи могут пересекаться в нескольких приложениях и системах знаний.

## Чему корпоративное ПО может научиться у программирования

Такой подход должен сократить разрыв в обучении с подкреплением между программированием и другими приложениями. Инструменты для программирования быстро развивались отчасти потому, что для кода уже существуют развитые средства развёртывания, отмены изменений и анализа новых версий.

Благодаря им проще создавать среды для обучения с подкреплением и проверять ИИ-системы на всё более сложных задачах по программированию.

Для большинства корпоративных программ таких инструментов пока нет. Когда они появятся, ИИ-системы смогут значительно лучше работать с корпоративным ПО, а другие отрасли получат возможности, похожие на те, что уже появились в программировании.

Управляющий директор General Catalyst Yuri Sagalov, который также руководит посевной программой фонда, говорит о растущем спросе на инструменты для проверки ИИ-агентов, такие как Arga Labs.

По словам Sagalov, значительная часть экономической ценности ИИ-агентов связана с использованием корпоративных приложений. Поэтому повторяемая изолированная среда особенно важна для агентов — гораздо важнее, чем она была для людей.
