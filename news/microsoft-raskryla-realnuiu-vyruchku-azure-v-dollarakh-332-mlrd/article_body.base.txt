# Microsoft впервые раскрыла выручку Azure в долларах: $33,2 млрд

Alphabet также отчиталась в среду: выручка Google Cloud за тот же квартал составила $30,7 млрд, немного меньше, чем у Azure. При этом Google Cloud, в который входят и подписки Google Workspace, примерно удвоил выручку за год и, по расчётам TechCrunch, рос примерно вдвое быстрее Azure.

Azure позволяет компаниям арендовать вычислительные мощности для запуска приложений и программного обеспечения как услуги, а также для создания и работы с моделями ИИ. По собственным данным Microsoft, это её крупнейшее и самое быстрорастущее направление. На Azure пришлось около 36% из $92,3 млрд квартальной выручки компании.

Выручка Azure оказалась примерно на $850 млн выше ожиданий аналитиков — $32,3 млрд. Темп роста в 48% также превысил прогноз финансового директора Microsoft Эми Худ: на июльском отчётном звонке она называла диапазон от 44% до 45%.

## Новая структура сегментов Microsoft

Azure теперь входит в сегмент Agents and Infra — один из двух новых бизнес-сегментов, которые Microsoft представила в этом квартале. Раньше компания отчитывалась по трём сегментам: Productivity and Business Processes, Intelligent Cloud и More Personal Computing.

В Agents and Infra объединены Azure и облачный бизнес Microsoft 365. За квартал сегмент принёс $76,8 млрд — на 25% больше, чем годом ранее.

Amazon опубликует отчёт в четверг. Аналитики также ожидают роста её облачного бизнеса Amazon Web Services. AWS остаётся крупнейшим облачным сервисом, и сейчас никто не ждёт, что Microsoft его обгонит. Но теперь все три компании раскрывают выручку в долларах, и борьба за лидерство становится нагляднее.
