# OpenAI buys startup whose tools already power Codex

## Tools for working with code

Pierre Computer Company has built several tools used in Codex:

- <strong>Trees</strong> helps users navigate project files quickly.
- <strong>Diffs</strong> shows code changes and lets users fix errors directly in the comparison window.
- <strong>Highlights</strong> highlights syntax in real time as a developer types or an AI agent generates code.
- <strong>Code Storage</strong> stores code and tracks its history with Git.

OpenAI says the acquisition is intended to make Git workflows work better when developers and AI agents write code at the same time. As agents take on more tasks in parallel, Git tools need to handle that workload.

OpenAI already uses its own version control system, Pando, built for developers and AI agents. Pierre’s open-source projects will remain open source. The deal is still awaiting regulatory approval.

Dataist’s take: OpenAI is strengthening the tools around Codex and expanding its infrastructure for people and AI agents to work together on code. Pierre’s projects will remain open source, while the deal’s completion depends on regulators’ decision.
