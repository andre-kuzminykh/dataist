# Anthropic добавила в Claude Code параллельных ИИ-агентов

[VIDEO:0]

Anthropic переработала функцию Projects в Claude Code. Пользователь описывает цель, после чего координатор распределяет работу между параллельными потоками. Каждый поток запускается в собственной облачной сессии.

Следить за ходом работы можно в главном чате или отдельно по каждому потоку — в том числе с мобильного устройства. Потоки умеют открывать запросы на слияние и запускать тесты. Со временем Claude формирует общую память между потоками, а библиотека собирает все загруженные файлы и результаты.

Бета-версия доступна отдельным подписчикам Pro и Max, которые используют облачные сессии в Claude Code. Доступ для Team и Enterprise появится позже. Локальный запуск также находится в планах. Для участия нужно записаться в лист ожидания.

Обновление продолжает курс Anthropic на автоматизацию программирования. Недавно компания сделала режим автопилота стандартным в Claude Code и заявила, что он превзошёл разработчиков-людей в задачах по безопасности.

Для подготовки к IPO такая стратегия тоже удобна: более автономные ИИ-агенты, вероятно, будут расходовать больше токенов. При этом контроль над объёмом расходуемых токенов постепенно переходит от пользователей к компании, которая их продаёт. Источник сравнивает это с ситуацией, когда газовые компании получают контроль над педалью газа в автомобиле.
