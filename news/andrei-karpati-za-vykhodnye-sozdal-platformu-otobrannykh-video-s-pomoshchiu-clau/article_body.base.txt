# Андрей Карпати собрал видеоплатформу HackerTube за одни выходные

[FIGURE:0]

## Что сделал Claude Code

Карпати поручил Claude Code почти всю работу — от анализа данных до настройки сервера. Вручную ему пришлось получить ключ API Google Cloud, арендовать сервер и купить домен.

По словам Карпати, проекты, на которые раньше уходили недели, теперь можно завершить за несколько часов. Для HackerTube Claude обработала комментарии Hacker News за два десятилетия и выделила 6454 видео, а TristanTube собрала из списка каналов Тристана Хьюма.

HackerTube не требует регистрации. Вместо миниатюр, подобранных для привлечения внимания, сервис показывает случайный кадр из середины видео; состояние просмотра хранится локально в браузере. Карпати считает, что такой подход обеспечивает более удобный просмотр, чем рекомендации YouTube.

По оценке Dataist, HackerTube показывает, как ИИ-агент может взять на себя значительную часть работы над небольшим сервисом — от обработки данных до настройки сервера. Однако Карпати всё же понадобились ручные действия: он получил ключ API, арендовал сервер и купил домен.
