# Agent Skills передали фонду Agentic AI Foundation

## Как устроены Agent Skills

Навык — это папка с файлом `SKILL.md`, который объясняет агенту, как выполнять конкретную задачу или работать в определённой области. В папке также могут быть скрипты и справочные материалы.

Agent Skills разработали во время работы над Claude Code. Он хорошо справлялся с общими рабочими задачами, но ему часто не хватало процедурных знаний, нужных для реальной работы в компаниях. Через несколько недель после запуска Claude Code в октябре 2025 года разработчики опубликовали на GitHub тысячи навыков и написали загрузчики для Codex, Cursor и OpenCode.

Затем стандарт Agent Skills опубликовали отдельно — с собственной организацией на GitHub и доменом, чтобы им мог пользоваться любой агент. С тех пор появилось 1 миллион навыков, а общее число установок приблизилось к 280 миллионам.

## Передача стандарта фонду AAIF

Разработчики намерены сохранить Agent Skills открытым, управляемым сообществом и независимым от отдельных поставщиков. Стандарт передают Agentic AI Foundation под эгидой Linux Foundation. В прошлом году создатели Agent Skills вместе с Block и OpenAI основали AAIF и передали фонду протокол Model Context Protocol (MCP).

AAIF станет нейтральной площадкой для развития стандарта: сообщество сможет влиять на его дальнейшее направление.

Фонду передают название и логотип Agent Skills, организацию на GitHub и домен `agentskills.io`. При этом пользоваться стандартом и вносить в него изменения можно будет и без вступления в AAIF.

Поддерживать стандарт будут инженеры Anthropic, Google, OpenAI и других компаний — как частные лица. Ведущими сопровождающими станут Дэвид Сория Парра и Махеш Мураг.

## Что планируют дальше

Авторы предложили начать с дорожной карты, которая охватит версии стандарта, официальный процесс подачи предложений и рекомендации по безопасности для тех, кто создаёт и устанавливает навыки. Как и в случае с MCP, проект будет учитывать мнение сообщества и принимать решения прозрачно.

Оставить отзывы о предлагаемых изменениях спецификации можно в Discord проекта. Создатели Agent Skills поблагодарили разработчиков, которые с самого начала создавали навыки, и команды, внедрившие их в свои продукты. Спецификация доступна на `agentskills.io`, а обсуждения идут на GitHub.
