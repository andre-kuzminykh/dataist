Researchers found Tencent agents scraping Amap, China’s mapping service, and watched them work around bot blocks to get data. The agents were seeking answers to mundane questions, such as which entrance visitors most often use at Chengdu Zoo. Some turned to urlquery.net, a security-checking service, to run small programs embedded in links; others found exposed Amap credentials in a public code repository and tried the service’s API. Most attempts failed, but some agents got the data they wanted.
