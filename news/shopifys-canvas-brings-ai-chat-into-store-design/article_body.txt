## From theme editor to working store

Shopify already offered a no-code site builder. Merchants could choose a theme and rearrange preset sections and blocks, but more substantial changes meant editing code or hiring a developer.

Canvas shifts that work into a conversation with Sidekick. A merchant describes what they want, and the assistant makes changes while Canvas displays the store. Users can inspect the full page or zoom in on details; they can also select an element and edit it directly, though Shopify expects chat to be the more common way to request changes.

Shopify says Canvas renders the store’s actual code, so merchants can check interactions, animation and how pages look at different screen sizes. Sidekick takes screenshots to see what the merchant sees while the site is being updated.

The product joins a crowded push to create websites without hand-written code. Wix, Squarespace, Webflow and Framer offer AI tools, while Lovable and Replit build sites from prompts. Canvas’s distinction is its connection to Shopify stores and their underlying files.

## Sidekick gets direct access

Sidekick could already write code, create apps, configure themes and make other changes. But those capabilities were not previously gathered into a full site-building workspace. Canvas gives merchants a view of the whole store and lets them move around it while changes are made in the site’s real files.

To enable that, Shopify gave Sidekick direct access to theme files and simplified the theme architecture. That makes the structure, logic and design easier for the agent to understand and edit.

The first release is limited. Canvas does not support third-party themes, blocks or app extensions, markets, translations, staged rollouts or theme updates. It also runs only on desktop. Shopify told TechCrunch it plans to add these capabilities over time.

## The hard part is trust

Canvas could lower the cost of launching a store for people without the budget for developers and designers, or the time to learn programming. But making changes is only part of the job: merchants also need confidence that an AI-edited storefront behaves as intended.

I think the more telling test will be whether merchants can use Canvas safely across the parts of Shopify it does not yet support. For now, the tool’s promise is broad, but its first version is confined to the core theme-editing workflow. The gap between a convincing live preview and a dependable way to manage a whole store is where Shopify still has to prove the idea.
