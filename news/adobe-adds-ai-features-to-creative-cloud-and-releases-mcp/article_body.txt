# Adobe adds AI features to Creative Cloud and releases MCP

[FIGURE:0]

## New Firefly tools

Firefly now has a feature called Builder, which lets users create mockups to present ideas. The tool is currently in closed beta and is aimed at tasks people use Figma for.

Adobe has also added a tool for creating graphics in a consistent brand style and an image editor. The editor can change one part of an image without affecting the other objects.

Firefly now has an AI tool for assembling videos from clips, images, sound effects and other elements. Adobe is also changing its creative AI agent: it will run continuously and gather more context about projects on its own, so it is ready to act. Quick operations include removing a background and creating a video thumbnail.

## Adobe app updates

At MAX, the company continued adding AI features to its apps. Photoshop will get a tool for changing lighting and sliders for controlling generative styles with prompts. Premiere will add a professional color-grading system and the ability to remove objects from video. Lightroom will learn to fix blinking in photos and remove skin blemishes.

Adobe already offers third-party models from Google, Runway, ElevenLabs, Black Forest Labs, OpenAI, Kling and ByteDance. Topaz Labs, one of the company’s recent acquisitions, is releasing two image models:

- <strong>Wonder 4</strong> — for upscaling and noise reduction.
- <strong>ImageHDR</strong> — for converting standard images to HDR.

## MCP for Creative Cloud

Adobe has already integrated ChatGPT and Claude so users can access some features in its products. The new local MCP is intended to make more Creative Cloud app features available through third-party chatbots.

Adobe vice president Deepa Subramaniam told TechCrunch that the company is still deciding which capabilities to provide through the protocol and will take user feedback into account. For now, MCP includes a set of endpoints and features for Illustrator, Photoshop, After Effects and Premiere. Adobe plans to track how people use these tools and what tasks they tackle, then add new capabilities. Subramaniam said the company is not looking to restrict access through MCP in advance; its goal is to support users’ creative workflows.

Last month, Dylan Field, co-founder of rival Figma, said at an event in India that MCP is an imperfect standard that benefits leading AI labs more.

Dataist's take: MCP could connect Adobe’s features to workflows in third-party chatbots, but the set of available capabilities is still subject to change. The company says it is defining that set based on user feedback, which means the integration’s final boundaries have not yet been set.
