OpenAI представила два обновления своей API-платформы. Новый Decisions API оценивает текст и изображения — или их сочетание — примерно в десять раз быстрее, чем Responses API. Сервис доступен в открытой бета-версии, общий запуск ожидается позднее. Пока API работает только с gpt-6-luna: миллион входных токенов стоит $0,10, выходные токены бесплатны. Одновременно OpenAI сократила число платных тарифных уровней с пяти до трёх.
