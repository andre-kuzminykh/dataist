Salesforce раскрыла следующий этап развития платформы Agent Fabric: она должна находить сбои в работе ИИ-агентов и запускать корректирующие действия. В планах — Agent Evals для проверки агентов, API Evals для тестирования их программных подключений и пользовательские сканеры для поиска агентов во внутренних системах. Бета-версии инструментов оценки ожидаются в ноябре, полноценный запуск — в январе 2027 года. Тогда же Salesforce планирует выпустить механизм отключения агента по результатам проверки. Базовый выключатель и часть инструментов контроля расходов уже доступны.
