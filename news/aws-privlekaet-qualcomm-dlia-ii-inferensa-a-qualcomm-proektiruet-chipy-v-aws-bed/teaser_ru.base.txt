Qualcomm разрабатывает для AWS специализированные чипы сразу для нескольких поколений продуктов, ориентируясь на инференс ИИ. Компании также создают оптические соединения с пропускной способностью до 1.6 терабита, чтобы справиться с растущим трафиком в ИИ-инфраструктуре. Qualcomm отвечает за энергоэффективную разработку чипов, AWS предоставляет облачную инфраструктуру, а сама Qualcomm использует Amazon Bedrock для ускорения проектирования. Для AWS это способ расширить линейку чипов для инференса, где затраты энергии на один токен напрямую влияют на экономику.
