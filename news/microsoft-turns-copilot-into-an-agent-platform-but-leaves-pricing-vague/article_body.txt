## What Microsoft is actually shipping

Microsoft’s update has three main parts:

- **Home** combines Chat with Cowork and is meant to route a user’s request to the right capability.
- **Code** generates applications, dashboards, automations and desktop widgets from written instructions.
- **Autopilot** runs continuously, with its own identity, memory, computing environment and workspace inside Microsoft 365.

The enterprise pitch is built around two questions: which work can be handed to an AI system, and how a company can control and pay for tasks that continue in the background.

At a presentation for VentureBeat on September 23, Microsoft CEO Satya Nadella said that every agent should have its own identity and that all of its actions must be tracked. That principle is reflected in Agent 365, which provides permissions, audit logs and administrative controls for Autopilot.

Autopilot is the new name for Scout, Microsoft’s earlier personal-agent initiative. A user gives the agent a goal and a role. The agent can monitor discussions, request updates, perform recurring duties and return to a project several days later. Employees interact with it through Teams, Outlook and documents, including by mentioning it as they would another participant.

Microsoft illustrated the model with a supplier review and a retail company preparing for Black Friday. In the demo, an Autopilot agent named Dot pulled information from email, Teams discussions, Dynamics 365 inventory data and spreadsheets. It found a supply problem affecting 18 stores, brought employees into the discussion and reported that the group had resolved the issue.

That is a useful description of Microsoft’s intended workflow, not evidence that Autopilot can reliably handle similar cases in customer deployments.

The Scout-to-Autopilot rename also leaves an important technical gap. When Microsoft introduced Scout in June, it identified the open-source OpenClaw project as its underlying technology and described adding enterprise identity and access controls. The new materials confirm the rename but do not explain how the internal architecture has changed.

## Copilot becomes a place to make and run software

Home extends Copilot beyond quick conversations. Its planned Today feature will collect signals from email, calendars, discussions and tasks, then prepare a draft follow-up or suggest a calendar change for the user to review. Microsoft plans to bring the same scenario to Outlook and Teams.

The Office integration brings Word, PowerPoint and Excel work into Copilot. Microsoft says users will be able to create and edit the same documents their colleagues are working on in the separate Office applications while keeping shared files synchronized.

In one demonstration, Microsoft product manager Monique Smith assembled a recommendation in Excel, checked a colleague’s contributions in Word and created a presentation from those materials. The workflow included tracked changes and later editing of the slides inside Copilot.

This puts Microsoft in the same direction as Anthropic, which on September 16 announced a combination of Claude’s chat, Cowork and tools for documents and slides. Anthropic’s system can also continue assigned tasks after the laptop is closed. Microsoft’s potential advantage is less about the chat interface than the surrounding estate: Office files, enterprise systems and administrative policies that customers already use.

Code takes the idea further by making the output deployable. It uses the same underlying technology as GitHub Copilot while adding corporate context and connected services. Professional developers can continue using GitHub Copilot; business users can create applications through Copilot.

Microsoft had already offered application generation through App Builder, introduced in October 2025 for Frontier participants. Those applications ran in Power Platform, with data stored inside the application or in SharePoint lists. Separate hosting was not required.

The new runtime changes the boundary:

- Earlier App Builder documentation prohibited calls to external APIs, and users could not inspect or directly modify generated code.
- The proposed runtime supports editable code and version control through Git.
- An SDK gives compatible external development tools access to Microsoft-managed hosting.
- Microsoft operates the platform while customer administrators control permissions and approved data connections.

Microsoft calls the infrastructure **Copilot Managed Runtime**. It hosts applications inside an organization’s Microsoft 365 boundaries and supports applications created through Copilot Studio, Cowork or Code. Developers can use the SDK and command-line tools to configure projects, preview changes and deploy updates while the existing application remains available.

Entra supplies identity services. Git tracks source code and versions. Administrators receive a single inventory of applications showing access, activity, status and policy compliance. In one demo, a sales application began with a spreadsheet, connected to corporate data and allowed assumptions to be changed during a customer conversation. Another combined account information with external signals in a personal workspace.

Microsoft executive vice president for Copilot Jacob Andreou said that hosting and sharing an application should become as easy as saving and sharing a Word document.

## The missing layer is operational certainty

Microsoft is extending FinOps controls from Agent 365 to Autopilot, Code and the managed runtime. Copilot Studio agents are expected to be added in October. Existing settings let administrators assign budgets, set limits and receive alerts, while billable services remain disabled until administrators allow access through spending policies.

The new controls include:

- Model access for specific groups, initially for Cowork.
- Limits on available model families, which also constrain automatic routing.
- Employee views showing credits spent, remaining limits and previous activity.
- Microsoft Graph APIs for managing spending policies and balances.
- Existing approval processes for requests for additional credits.
- Cowork reporting intended to connect resource consumption with useful outcomes.

Microsoft is also adding more business context to its AI tools:

- **Fabric IQ** adds enterprise-data context to Chat and Cowork.
- **Work IQ** gains connections to Power Platform and Dynamics 365.
- A **shared plugin registry** gives administrators one place to approve Microsoft, partner and internal extensions.

The reporting dashboard is the least settled part of that story. Microsoft says it should help managers decide which workflows to expand, but the launch materials do not explain the measurement methodology in enough detail to treat the panels as proof of financial return.

My read is that Microsoft is selling governance as much as autonomy. The company wants agents to act across corporate systems, but it also wants every identity, permission, model choice and credit balance to remain inside an administrative framework. That makes the product more plausible for large organizations than an unbounded personal agent, but it also makes the quality of the controls part of the product itself.

The announcement is quiet about the most consequential operational details: how Autopilot gets approval for individual actions, how administrators handle every class of failed operation, and how a company calculates the cost of a task that runs for days. Those omissions matter more than another application demo.

## Pricing is still a calculation, not a number

Microsoft has not provided detailed pricing for the new capabilities. Buyers cannot yet calculate the cost of a continuing Autopilot task, a Code project or an application running on managed hosting.

The announced model separates ordinary Copilot interactions from usage charges for larger agent workloads. Microsoft lists Autopilot, Cowork and Code among consumption-priced capabilities, alongside the advanced Astra and Fable models.

Current US pricing provides several licensing levels:

- Included at no additional charge for eligible Microsoft 365 subscribers using Entra accounts. Agent work may still be charged separately by usage.
- $30 per user per month with annual payment, on top of an eligible Microsoft 365 subscription.
- $21 per user per month at the standard price; a promotional price of $18 applies with annual payment for the first year. An eligible Business subscription is required, with support for up to 300 users.
- $99 per user per month with annual payment for a package combining E5, Copilot, Agent 365 and Entra Suite.
- $15 per user per month with annual payment as a standalone offer; it is also included in E7.

The Business promotion applies to eligible purchases through December 31, 2026, with the discount lasting only through the first year.

Cowork already uses variable pricing. At its general launch on June 16, Microsoft required a Copilot subscription plus usage charges of $0.01 per Copilot credit, with discounts available for prepaid bundles. A credit is a billing unit, not the price of a whole task: Microsoft says the total depends on the model, retrieved context, tools invoked and execution time.

Earlier Scout terms were less specific. Microsoft’s June partner notice tied pricing to usage and promised further spending guidance. The $99 E7 subscription therefore cannot be treated as a universal Scout or Autopilot price. Existing Scout setup documentation also listed Microsoft 365 Copilot and GitHub Copilot Business or Enterprise licenses as requirements, while the new materials do not explain how those requirements carry over.

Microsoft says Agent 365 spending controls are included with cloud subscriptions. That does not mean runtime hosting is free or that agent execution is unlimited.

Availability will be phased:

- Home and Office integration will begin reaching Frontier participants over the next few weeks, with Office integration also rolling out to regular users.
- Code is expected in Frontier in late September, followed by a broader launch.
- Microsoft plans to expand early access to Microsoft 365 Premium or Pro subscribers later in 2026.
- Autopilot’s closed test will expand at the end of the month.
- The managed runtime and SDK will enter public preview.
- Today’s closed test is planned for October.
- Fabric IQ integration with Cowork and Chat is moving into general availability.
- The Work IQ expansion will enter public preview within the next month.
- The shared plugin registry should reach general availability by the end of September.
- General Copilot interactions through the @ symbol in Teams will also begin closed testing at the end of the month.

Microsoft has assembled the pieces of an enterprise agent platform: persistent identities, shared workspaces, generated applications, managed hosting and spending controls. Until the company explains how those pieces are priced and how failed actions are governed, the platform is easier to demonstrate than to budget for.
